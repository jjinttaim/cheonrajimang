# ADR: 주변 시설은 비교 가능한 행동 가정으로 연결

상태: 구현. 날짜: 2026-09-18. 정확도와 계수 학습은 미검증.

## 맥락

편의점·식당·정류장·숙박·의료·도움 요청 장소는 이동 선택에 영향을 줄 수 있다. 그러나 POI 위치는 관측 자료인 반면 그곳을 향하는 선호는 아직 관측되지 않은 가정이다. 기존 승인된 수색 장부와 확률 불변식을 보존해야 한다.

## 결정

OSM의 분석 범위 내 시설 630개(현재 계산 적격 격자 619개)를 별도 버전으로 보관한다. 종류는 편의점/마트 44, 식당/카페 81, 음수대 4, 정류장/터미널 411, 쉼터/숙박 53, 병원/약국 31, 경찰/소방 6이다. 미등록 시설, 폐업, 영업 중 여부와 현장 출입 가능성은 확인하지 못했다.

시설 영향은 **B′ 행동 시나리오만** 바꾼다. A 거리와 B 지형은 시설 없는 비교 기준으로 유지한다. 종합 A½/B¼/B′¼는 기존 가중치를 유지한다. 새 모의 수색 폼에서 켜기/끄기와 0~1 강도를 선택한다. 기본 UI 강도 0.6은 **방문 확률 60%가 아닌 임의 감도 계수**다. 기존 API/구버전 임무 기본값은 꺼짐이다.

1. 격자 간 지형 이동시간을 유향 그래프로 만든다. 수역·45° 초과 경사·미분류 셀은 시설 접근 경로에서 제외하고 대각선으로 장벽 모서리를 가로지르지 않는다. 시설 폴리곤은 공개 중심점을 사용하므로 실제 출입구와 다를 수 있다.
2. 시설까지 걸리는 최소 모형 시간을 그래프를 뒤집어 계산한다. 모든 시설 종류는 동일 가중치이며 가장 가까운 적격 시설 하나의 영향만 사용한다. private/no 출입 태그 시설은 계산 씨앗에서 제외한다.
3. `U(x)=exp(-T_nearest(x)/900초)`, `b=clip(8×strength×(U(next)-U(current)), -0.7, +0.7)`. 900초·8·0.7은 팀 가정이다. 시설 종류별 성향을 학습한 숫자가 아니다.
4. 기존 경로/경사 이동 수락 규칙의 로그 선호에 b를 더한다. 한 스텝의 실제 모형 이동시간과 경과 시간 예산은 유지한다. 시설 위치로 입자나 확률을 순간 이동시키지 않는다.
5. 격자 밖으로 나가는 스텝에는 시설 보정을 0으로 둔다. 수역의 기존 존재 확률, 지도 밖 잔여, 위험 구역의 기관 전용 게이트는 유지한다.
6. 저장된 사후분포의 시간 전파에도 같은 필드를 쓴다. 과거 미발견 강도를 다시 적용하지 않는다.

시설 데이터/격자는 내용 해시 디렉터리에 남긴다. 새 임무의 입력·영수증에 시설 snapshot, 강도, 출처, 수집시각을 고정하고 ZIP에도 시설 GeoJSON·영향 격자·메타데이터를 포함한다. 기존 임무를 소급 변경하지 않는다.

## 대안과 비용

- 모든 시나리오에 시설 주변 확률을 일괄 곱하기: 지형·시간과 무관한 이동 및 단일 가정 과신을 만들기 쉬워 채택하지 않았다.
- 실제 사례로 종류·시간대별 방문 계수 학습: 관측 시설 방문 정답과 당시 영업·교통 상태가 필요하다. 이번 공개 자료에는 없어 미구현이다.
- 강도를 사람별로 자동 추정: 건강·심리 상태를 근거 없이 추정하지 않기 위해 미구현이다.

최근접 시설 가정은 시설 밀도가 높은 정류장에 영향을 많이 받을 수 있다. 중복 node/way 표현, OSM 누락, 중심점 오류, DSM/2021 토지피복의 오래된 상태가 있다. 시설을 목적지로 인지하는지, 도착 후 체류하는지, 버스를 타는지, 실제 교통 혼잡과 야간 영업은 계산하지 않는다. 연구 데이터 수집은 수행했지만 이 모델의 계수를 학습하지 않았다.

## 검증

- 강도 0: 기존 B′와 배열 일치.
- 켜기: A/B 불변, B′ 및 B′ 시간 전파 결과 변화.
- 수역 장벽 반대편 시설 영향 0, private 시설 제외.
- 모든 분포에서 격자 질량+외부 질량=1.
- 물에 있는 입자 질량 유지, 시간 0에서 미발견 증거 중복 적용 없음.
- 시설 입력/해시 고정, 기존 임무 영수증 불변, 인계 ZIP에 입력 포함.

관련 구현: `backend/facilities.py`, `pipeline/prepare_facilities.py`, `backend/core.py`, `backend/live.py`, `backend/tests/test_facilities.py`.
API: GET /api/facilities?snapshot=해시. POST /api/missions의 facility_influence, facility_strength.
화면: 주변 시설 패널 → 시설 가정을 켜서 새 임무 → B′ 비교 → 시간 미리보기 → 영수증/인계.

## 다음 단계

시설 인지·도달·체류를 구분한 동의 기반 모의 보행 실험, 시설 유형별 ablation, 시설 가정 없는 모델 대비 사건 단위 평가가 필요하다. 현장 위험 구역의 일반팀 출입은 가정 강도와 무관하게 별도 승인 대상이다.
