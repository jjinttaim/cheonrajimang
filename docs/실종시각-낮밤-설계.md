# 실종 시각·낮밤 반영 — 2026-09-19

## 요구사항과 경계

마지막 확인 시각과 계산 기준 시각을 구분하고, 같은 경과시간이라도 낮/밤 이동 가정을 다르게 적용한다. 계수는 관측·학습값이 아니다. 기존 임무를 다시 계산하거나 덮어쓰지 않는다. 최종 제품은 훈련용 판단 보조이며 실제 위치를 알아내는 도구가 아니다.

`시각·위치 입력 → 태양고도/분 단위 이동계수 → B/B′ 이동시간 적분 → 시나리오 분포 → 가정·기준시각 영수증`

## 입력·저장 계약

- `POST /api/missions`: 선택 입력 `missing_at`, `analysis_at`(시간대가 있는 ISO 시각), `daylight_enabled`, `night_factor`(0.3–1.0, 기본 0.6).
- 시각을 입력하면 두 시각 차이로 `hours`를 계산한다. 허용 범위는 기존 엔진과 같은 15분–8시간이다. `analysis_at`을 생략하면 서버 시각을 한 번 고정한다.
- 낮밤 기능에는 마지막 확인 시각이 필수이다. 시각 순서·범위·시간대를 검증하고, 한국시간 입력을 브라우저의 현지 시간대로 해석하지 않는다.
- 새 임무의 `daylight_model=solar-mobility-assumption-v1`과 야간 계수·시각을 파라미터에 고정한다. 변경을 비교하려면 새 임무를 만든다.
- v0 영수증의 `state_at`은 지도 계산 기준시각, `created_at`은 실제 버전 저장시각이다. 이후 미발견 승인 버전의 `state_at`은 승인 스냅샷 시각이다. 기존 절대시각 없는 임무는 이전의 상대시간 계산을 유지한다.

## 계산 정의

1. [NOAA 일반 태양위치식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)으로 마지막 확인 위치의 태양 중심 고도를 근사한다. 굴절·산/건물 가림·구름·달빛·가로등은 계산하지 않는다. 관측 일출/일몰시각을 제공하는 서비스가 아니다.
2. 고도 ≥0°는 낮, −6° 이하는 밤, 사이는 해 뜰녘/질녘으로 표시한다. 낮 계수는 1, 밤은 사용자 가정값, 사이는 선형으로 연결한다. 60초 고정 구간의 중간 시각으로 계수를 구한다.
3. 실제 시각의 계수를 적분한 이동 시계 `U(t)=∫f(s)ds`를 만든다. 지형 속도가 `v`인 구간은 `v × [U(t+Δt)−U(t)]`만큼 이동할 수 있다. 한 이동 구간 중 해가 뜨거나 져도 처음 밝기만 끝까지 적용하지 않는다.
4. 최초 시나리오 B/B′에 적용하고 A는 시간 효과가 없는 거리 비교 기준으로 유지한다. 이후 시간 추정은 기존과 같이 각 기준 분포를 이동시키므로 A에서 출발한 분포에도 같은 도보 낮밤 시계를 사용한다.
5. 물·급경사의 종착 상태와 지도 밖 질량은 보존한다. 밤이라고 물 주변 확률을 없애거나 수색대의 위험 구역 진입을 허용하지 않는다.
6. 미발견 증거는 기존처럼 한 번 적용한 뒤 이동한다. 낮밤만으로 POD나 수색 흔적을 변경하지 않는다.

## 화면과 API

새 모의 수색의 **실종 시각·낮밤 반영**을 켠다. 마지막 확인 시각·기준 지도 시각(KST)과 야간 계수를 정한다. 초기 구간의 낮/해 뜰녘·질녘/밤 분량을 화면에 보여 준다.

시간 미리보기·실시간 추정에서는 `receipt.state_at` 이후 시각으로 계산한다. 응답 `speed.daylight`에 사용한 기준 위치·시각·태양고도·구간별 분량·가정값·가정 버전을 포함한다. 저장 임무·과거 영수증을 쓰지 않는 조회이다. 새 날짜 입력이 없는 과거 임무는 기능 꺼짐을 명시한다.

## 선택한 절충과 다음 단계

- 별도 외부 API·인증키 없이 계산하며 장기 실행 작업·새 저장소를 추가하지 않았다. 같은 입력·모델 버전이면 같은 결과를 얻는다.
- 한림읍 약 15 km 영역에서는 마지막 확인 지점의 공통 태양 시계를 사용한다. 입자마다 지형 그림자를 계산하는 기능은 아니다. 지형·날씨·실측 조도가 필요해지면 별도 검증된 입력 모듈로 확장한다.
- 야간 0.6은 실측 통계가 아니다. 0.3–1.0을 비교할 수 있지만 이 범위도 통계적 신뢰구간이 아니다. 수면/정지 확률·개인의 인지 상태·시설 영업을 추론하지 않는다.
- 낮밤 켜짐 상태가 추천을 과신하게 만들 수 있어 ‘학습 전’ 표시와 가정의 적용 대상을 명시한다. 근거가 확보되기 전에는 학습값으로 바꾸지 않는다.
- 8시간 초기 모형·6시간 이후 추정 상한은 유지한다. 수색 관측 시각별로 전체 이동/관측을 재생하는 필터는 아니다. GPS 승인 시각을 스냅샷 기준으로 삼는 기존 한계도 남아 있다.
- 학습 구성과 데이터 한계는 [AI 학습 시작하기](AI-학습-시작하기.md)를 따른다. 수색자 속도 학습 결과를 실종자 속도나 POD에 자동 연결하지 않는다.

## 검증 항목

일/야간과 여름/겨울·윤년·UTC/KST 동치, 새벽 전후 적분과 경로 시간 일관성, 0초 위치 불변, 야간 이동거리 감소, 질량 합 1, A와 과거 임무 불변, 야간 계수 1에서 기존 계산 일치, 시각 검증, 최초 기준시각·후속 승인시각 앵커, 조회 전후 영수증 불변을 검사한다. 브라우저는 임시 DB와 해외 시간대에서 실제 시각 입력·새 임무·미리보기·모바일 화면을 검사한다. 이 검사는 코드 동작이며 실종자 행동의 검증이 아니다.
