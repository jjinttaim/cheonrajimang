# 천라지망 일반 보행 학습 결과

2026-09-20. **실제 자료 정제 → 실제 적합 → 사람별 분리 평가 → 실행 가능한 JSON 모델 → 앱 실험 화면**까지 완료했다. 실종자 위치 예측기의 현장 검증 완료를 의미하지 않는다.

## 바로 실행

앱을 실행한 뒤 [보행 학습 실험실](http://127.0.0.1:8000/?view=walking-lab)을 연다. 기존 화면 오른쪽 위 **보행 학습 결과 ↗**로도 들어간다.

- 0–300초를 선택하면 학습된 30초 이동 규칙으로 4,096개 가상 경로를 생성한다.
- 초록은 생성된 도착점 분포, 황색은 그중 12개 경로이다. 실제 사람의 GPS를 표시하지 않는다.
- 같은 모델·시간·시드는 같은 결과를 낸다. 시간 확대 시 앞부분의 생성 경로가 유지된다.
- 상대 좌표상의 연구 시연이며 지형·편의점·밤·교통·수색 관찰을 반영하지 않는다. 기존 임무 지도·경로 추천·인계 결과에는 적용하지 않는다.

## 실제 사용한 데이터

Microsoft 공식 GeoLife 1.3(약 313 MB)을 내려받아 ZIP CRC·SHA-256을 확인했다. 실제 압축 목록은 182명, 18,670개 궤적, 69개 라벨 파일이다. 보행 라벨을 가진 사람은 63명이다. 안내서 일부 숫자(73명 라벨, 17,621개 궤적)는 이 아카이브와 달라 그대로 인용하지 않았다.

`walk`로 표시된 기록만 골랐다. 중복 궤적, 겹친 라벨, 15초 초과 GPS 공백, 비증가 시각, 순간속도 4 m/s 초과를 처리하고, 끊기지 않은 구간에서 30초 간격으로 표본을 만들었다. 100개 이상 유효 표본을 가진 사람만 포함했다.

| 분할 | 사람 수 | 30초 예측 표본 수 | 사용 목적 |
|---|---:|---:|---|
| 학습 | 15 | 37,469 | 전이 확률·대표 속도 적합 |
| 검증 | 5 | 10,278 | 별도 성능 확인, 재적합 없음 |
| 최종 평가 | 5 | 5,507 | 마지막 평가 |
| 합계 | 25 | 53,254 | 같은 사람이 두 집합에 들어가지 않음 |

**53,254개를 모두 학습한 것은 아니다. 실제 적합에는 37,469개만 사용했다.** 일상 보행·중국 중심·2007–2012년 자료이다. 실제 실종자, 특정 질환, 한국 지형에 대한 정답으로 바꾸어 해석하면 안 된다.

추가 품질 감사:

- 중복 제거 후 살핀 입력: 10,268개 트랙 / 11,314,683개 점. 명확한 보행 라벨에 속한 점 1,448,891개.
- 보행 구간 안에서도 비증가 시각 237,180쌍, 15초 초과 공백 20,255쌍, 속도 기준 초과 62,083쌍이 있었다. 이 수치는 서로 겹칠 수 있다. 원자료가 많다고 모두 신뢰 가능한 학습 표본은 아니다.
- 각 고유 입력 트랙 첫·끝 시각 20,536개를 숫자 시간과 날짜 문자열로 교차 확인했다. 1초 초과 불일치 0개. 모든 점의 문자열 시간까지 검사한 것은 아니다.
- 절대 좌표는 정제 학습표에 저장하지 않았지만 원 ZIP에는 실제 궤적이 있으므로 민감하게 관리한다. 익명 ID·시각 역시 외부 공개하지 않는다.

## 어떤 AI인가

**데이터로 확률을 적합한 Markov 이동 모델**이다. 신경망은 아니다.

입력: 직전 30초의 순이동 속도 범주. 출력: 다음 30초의 속도 범주 6개 × 회전 범주 9개의 결합 확률. 방향이 불확정인 저속 상태도 별도로 둔다. 많이 기록한 사람이 지배하지 않도록 사람마다 총 가중치를 같게 했다. 확률에 Dirichlet 0.5 평활을 적용했다.

기준 모델은 직전 속도를 무시한 전체 이동 빈도 분포이다. 시연의 초기 방향·속도 상태, 30초 전이 반복, 속도 범주 대표값은 별도의 생성 가정이므로 장기 위치 분포의 검증과 동일하지 않다.

## 실제 최종 평가 결과

모두 사람별 평균을 다시 평균한 값이다.

| 지표 | 전체 빈도 기준 모델 | 학습 모델 |
|---|---:|---:|
| 다음 속도·회전의 음의 로그우도(NLL, 낮을수록 좋음) | 2.587123 | 2.001106 |
| 결합 범주 Brier score(낮을수록 좋음) | 0.881791 | 0.746214 |
| 다음 평균 순이동 속도 절대오차 | 0.466095 m/s | 0.282630 m/s |

NLL 상대 개선 **22.65%**. 사람 단위 paired bootstrap 2,000회 개선 구간은 **0.416586~0.794086 NLL**이다. 이는 정확도 22.65% 또는 발견률 개선이라는 뜻이 아니다. 평가 인원이 5명뿐이라 재표집 구간만으로 일반화를 주장할 수 없다.

학습 후 추가로 더 강한 단순 기준인 **직전 속도 그대로 유지**를 확인했다. 속도 오차가 **0.262957 m/s**여서 학습 모델의 0.282630 m/s보다 낮았다. 따라서 이 모델이 모든 단순 방법보다 우수하다는 결론도 내릴 수 없다. 이 사후 점검은 기존 분할·모델·채택 기준을 바꾸지 않았다.

## 채택 판정: NOT_ADOPTED

후속으로 출발 위치만을 아는 조건에서 실제 5분 보행 214구간을 비교했다. 5분 모델 80% 반경의 실제 포함률은 사람별 평균 72.6%였고, 일정 속도·방향 기준 대비 평균 점수 개선의 재표집 범위가 0을 포함했다. 결과를 앱에 추가했으며 모델·판정은 유지했다. [시간 예측 검증 결과](AI-GeoLife-시간예측-검증결과.md).

[사전에 고정한 계획](AI-GeoLife-사전검증계획.md)은 전체 최소 30명, 최종 평가 최소 6명, NLL 개선 ≥1%, 개선 구간 하한 >0을 모두 요구했다. 실제 인원은 **25명 / 평가 5명**으로 인원 기준에 미달했다. 성능 숫자가 좋게 나와도 기준을 낮추지 않았다.

따라서 **실행 가능한 학습 결과는 제공하지만 실종자 수색 엔진의 기본값으로 배포하지 않는다.** 연구 실험실에서만 실행한다. 원래 목표인 시간별 실종자 존재확률·안전한 자동 수색 계획의 검증 완료는 아니다.

## 결과물과 재현

아래 `data/models/walking_reference/`·`data/ml/geolife/` 파일은 MSR-LA 조건 때문에 로컬 전용이며 깃허브 저장소에 포함하지 않는다. 이를 읽는 테스트(`backend/tests/test_walking_reference.py`)는 파일이 없으면 건너뛴다.

- 학습 모델: `data/models/walking_reference/a0d0ebfd08ac11f565e119ac44d9b92dd76fb286e6aeae780b3c130c5b6390b1/model.json`
- 같은 폴더의 `evaluation.json`: 사람별/분할별 평가, bootstrap 결과.
- 같은 폴더의 `inventory.json`, `receipt.json`: 출처, 분할, 데이터·코드·프로토콜·모델 해시.
- 정제 자료: `data/ml/geolife/walking_samples.npz` (로컬 연구 전용).
- 품질 감사: `data/ml/geolife/quality_audit.json`.
- 추가 속도 기준: `data/ml/geolife/persistence_check.json`.
- 화면 증거: `artifacts/geolife-walking-desktop.png`, `geolife-walking-mobile.png`, `geolife-walking-mobile-chart.png`.

실제 실행한 순서:

```sh
.venv/bin/python -m pipeline.collect_geolife
.venv/bin/python -m pipeline.prepare_geolife
.venv/bin/python -m pipeline.train_geolife
.venv/bin/python -m pipeline.audit_geolife
.venv/bin/python -m pipeline.check_geolife_persistence
```

기존 산출물을 덮어쓰지 않도록 준비·학습 코드는 결과가 이미 있으면 중단한다. 현재 모델을 재학습해 값이 같은지 확인하는 비파괴 검사는 다음과 같다.

```sh
.venv/bin/python -m pytest backend/tests/test_walking_reference.py backend/tests/test_geolife_prepare.py -q
```

검사는 학습 확률의 완전 재현, 사람 분리, 평가 수치 재계산, 확률 총합, 시드 재현, 시간 확장 경로 일치, 변조 모델 거부, 기존 임무 불변, 모델의 웹 파일 공개/인계 ZIP 포함 금지를 확인한다.

실행 확인: 백엔드 전체 92개, 프런트 단위 14개 통과. `frontend/walking-check.mjs`는 데스크톱·390px 모바일, 시간/시드 변경, 진입 링크, 임무 불변을 확인했다. 빌드는 성공했으며 기존 대형 번들 경고는 남는다. 서버 재시작 후 새 API에서 4,096개 경로·확률 총합 1을 확인했고, 기존 6개 버전의 정렬 `(mission,number,hash)` JSON SHA-256 `f247688f414eb89c2d9cf4baf97e0e6aa6ae4d267d410bd8bb17fe71d3e91419`는 그대로였다. 기존 `fa9c4ef…` 모델 묶음도 유지했다.

## 이용 조건과 다음 실험

동봉 MSR-LA는 비상업적 연구·교육·공개 시연 등을 허용하되 원자료 및 파생물 재배포 금지 문구가 있다. 원본·정제 자료·모델을 로컬에 보관하고 외부 업로드나 인계 ZIP에는 넣지 않았다. 모델의 외부 배포·상용화는 별도 조건 확인 전 진행하지 않는다. 원본과 이용 조건 확인 기록은 `data/research/geolife_2012/NOTICE.md`에 있다(로컬 전용, 깃허브 저장소 미포함).

다음 개선은 보행만으로 학습한 모델을 곧바로 실종자에게 적용하는 것이 아니다. 시각 중복과 공백의 원인을 확인해 별도 버전의 정제 계획을 만들고, 아직 평가에 쓰지 않은 사람/다른 지역 자료를 확보한 후 장기 경로 오차와 단순 속도 유지 기준을 비교해야 한다. 지형·낮밤·시설·대상 유형은 해당 입력과 결과가 함께 관측된 자료 또는 명시적 가정으로만 추가한다. 실제 실종자 행동 및 수색 탐지 정답은 여전히 별도로 필요하다.
