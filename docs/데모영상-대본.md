# 천라지망 90초 데모 영상 — 대본·스토리보드·녹화 가이드

예선 서류(9/27)와 함께 제출하는 90초 영상용. 모든 장면은 2026-09-20 기준 실제 실행 화면으로 찍는다. 합성 자료·훈련 임무만 사용하고, 화면의 "TRAINING / 실제 사건 아님" 표시를 지우지 않는다.

## 한 줄 메시지

"민간 수색은 이루어지지만 증명되지 않는다 — 천라지망은 그 증명을 만든다."

## 미리 준비할 것

1. `start.command`로 서버를 띄우고 `http://127.0.0.1:8000`을 연다. 데모용 임무를 하나 만들어 둔다(이름 "한림읍 훈련 시연", 낮·밤 가정 켜고 마지막 확인 18:30, 기준 21:30, 시설 가정 켬, 거리 시나리오는 기본값 학습 모델).
2. 브라우저 창 크기 1440×900, 배율 100%, 시스템 다크모드 끄기. 북마크바·확장 프로그램 숨김.
3. 휴대폰 컷은 같은 Wi-Fi에서 `http://<Mac IP>:8000/?view=join`으로 접속한다. 서버가 127.0.0.1에만 열려 있으므로 실기기 촬영이 필요하면 촬영 시간 동안만 `--host 0.0.0.0`으로 띄우고 끝나면 즉시 내린다. 실기기가 어려우면 브라우저 반응형 모드(390×844)로 찍는다.
4. 인터넷이 없으면 벡터 지도 대신 저해상도 분석 지도로 떨어진다. 촬영 전에 `고해상도 벡터` 표시를 확인한다.
5. 녹화 도구: macOS `⌘⇧5` 화면 녹화(마이크 끔), 자막·내레이션은 편집 단계에서 얹는다. 커서는 크게, 클릭마다 0.5초 멈춤.

## 편집 규칙

- 총 길이 90초 ±2초. 자막은 한 화면에 두 줄 이내, 최소 14pt 상당.
- 화면에 실제 인물·실명·주소가 나오면 안 된다. 합성 임무 이름과 훈련용 가상 정보만 쓴다.
- "AI가 위치를 찾아낸다"류의 표현 금지. 대본의 "단정하지 않습니다", "가정", "미채택"은 그대로 둔다.
- 수치는 화면에 보이는 값만 말한다(72.3%, 0.253 m/s, 65건, 61트랙, 11.5%, 10.3 ha).
- 마지막 프레임에 데이터 출처 한 줄: "Copernicus DEM · ESA WorldCover · OpenStreetMap · Hashimoto et al. 2022/2026 (CC BY 4.0)".
