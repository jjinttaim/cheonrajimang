# 실제 사건 지형·발견점 모델: 학습 전 고정 계획

2026-09-19. 이 파일은 지형 특성과 발견 위치의 관계를 적합하기 전에 작성했다. 사전에 기존 65건의 좌표 범위·거리 범위·자료 해시만 확인했다. 후속 실행은 이 파일의 SHA-256을 남기며 평가 결과를 보고 본문을 바꾸지 않는다.

## 목표와 범위

65개 미국 하이커 사건의 실제 마지막 확인 위치·발견점을 사용한다. **시각별 존재 위치나 이동속도가 아닌 발견점 분포**를 학습한다. 기존 시간 이동 가설·POD·수색대 속도 모델을 이 자료로 재학습하지 않는다. 사건별 사후 적합 파라미터와 모의 궤적은 사용하지 않는다. 기사를 결합해 실종자 신원을 알아내지 않는다.

원자료 파생 CSV: `data/research/prepared/incident_endpoints.csv`.

## 독립 지형 입력

Copernicus GLO-90의 AWS 공개 2021 release COG를 원본 타일로 보관한다. 각 사건의 실제 좌표 주변 자료를 사용한다. GLO-90은 식생·건물도 포함하는 DSM이며 순수 지표 DTM이 아니다. 사건 날짜가 없으므로 해당 사건 당시의 지형과 일치한다고 확정하지 않는다.

- 반경 20 km, 반경 간격 250 m × 방위 간격 5도: 80 × 72개 극좌표 구역. 사건 마지막 위치만으로 범위를 고정하며 발견점으로 확대/이동하지 않는다.
- WGS84 타원체 지오데식으로 구역 중심과 발견 구역을 계산한다. 20 km 밖 발견은 outside 한 범주로 남긴다.
- 중심점 DSM 높이와 마지막 위치 DSM 높이의 차이 / 500 m, [-4,4]로 고정 제한.
- 중심점의 동서남북 90 m 지점 DSM으로 중심 차분해 얻은 지표면 경사각 / 30도, [0,3]으로 고정 제한.
- COG의 원래 해상도에서 최근접 표본을 사용한다. 이 입력은 미래 궤적·발견 여부에서 계산하지 않는다. 위험 셀을 확률 0으로 만들지 않는다.
- 해상 타일 부재는 공개 타일 목록과 공급자 설명으로 확인된 경우만 높이 0으로 처리한다. 네트워크 실패/잘못된 파일/NoData를 0으로 바꾸지 않는다. 결측 발생 시 해당 사건을 임의 제외해 학습하지 않고 준비 단계 실패를 보고한다.

최초 버전은 지형 변수 두 개만 사용한다. 도로·시설·밤 여부 효과를 배웠다고 주장하지 않는다. 타일 URL·수집 시각·HTTP 메타데이터·SHA-256과 준비 코드 버전을 기록한다.

## 모델

기준 모델: 각 훈련 fold의 실제 WGS84 발견 거리로 로그정규 분포를 적합한다. 각 반경 띠의 정확한 CDF 차이를 72개 방위로 균등 분배한다. 밖 질량은 1−CDF(20 km)이다.

지형 후보: 동일한 기준 질량에 exp(β₁·상대고도 + β₂·경사각)를 곱한 뒤 원 안에서 정규화한다. 원 밖 질량은 그대로 보존한다. 두 계수는 훈련 사건의 발견 구역 음의 로그 확률 평균 + 0.1/2 × ||β||²를 최소화해 학습한다. 초기 β=0, 각각 [-3,3], L-BFGS-B, 최대 200회, gradient tolerance 1e-7. 고정 수치 설정이며 검증 점수를 보고 변경하지 않는다.

두 모델 모두 구역 질량 + 밖 질량 = 1을 검사한다. 지형 구역 중심을 대표점으로 쓰는 해상도 근사가 있으며 개별 건물·낭떠러지 단위 정확도를 주장하지 않는다.

## 분할·평가

주 평가는 마지막 위치의 정수 위도·경도 1도 묶음을 하나씩 제외한다. 평가 사건 마지막 위치에서 40 km 이내인 다른 훈련 사건도 제외해 반경 20 km 지형 범위가 겹치지 않도록 한다. 이는 알려지지 않은 동일 인물/사건 중복을 완전히 차단하는 증명은 아니다.

훈련 사건이 20개 미만인 fold 또는 수렴 실패는 실패로 기록하고 전체 성공을 주장하지 않는다. 계수·거리 분포는 각 fold 훈련 사건만으로 적합한다. 평가 사건의 실제 거리를 모델 입력으로 넣지 않고 발견 구역 평가에만 쓴다. 별도 검증으로 leave-one-case-out도 계산하되 후보 선택에는 쓰지 않는다.

주 지표: 동일한 극좌표 구역에서의 사건별 NLL 차이(지형−기준). 낮을수록 좋다. 보조 지표: 원 안 동일 면적 상위 10/20/30%에 실제 발견 구역이 들어오는 비율. 구역 크기가 반경에 따라 다르므로 질량/면적으로 정렬하고 면적 예산을 초과한 구역은 넣지 않는다. 20 km 밖 발견은 세 적중률 모두 실패로 센다.

25개 공간 묶음(실제 준비 자료에서 재확인)을 단위로 2,000회 paired bootstrap, seed 20260919로 NLL 평균 차이의 탐색적 95% 분위수 범위를 보고한다. fold 간 훈련 자료 중첩 때문에 엄밀한 외부 확증 구간으로 부르지 않는다. 사건별·공간별 결과, 제외 수, 훈련 수, 모든 실패를 남긴다.

**앱 비교 후보 채택 조건:** 주 평가 전 사건 성공, NLL 평균 차이 <0, bootstrap 상한 <0, 상위 20% 면적 적중률이 기준보다 낮지 않음. 불통과해도 결과와 적합한 계수는 연구 아티팩트로 보존하되 현재 앱 모델에 자동 등록하지 않는다. 통과해도 국내/시간별 모델 검증이 아니며 별도 명시적인 연구 비교 모드만 가능하다.
