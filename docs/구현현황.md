# SearchProof 첫 실행 버전 — 2026-09-18

## 범위

기존 설계서 전체의 완료판이 아니라, 조정자 한 명의 모의 수색 의사결정 흐름을 구현한 로컬 MVP이다. 실제 데이터와 가정·모의 입력을 구분한다. 기존 문서는 수정하지 않았다.

## 비평 반영 내역

| 쟁점 | 반영한 구현 | 남은 한계 |
|---|---|---|
| 통행 불가 = 존재 불가 | 수역·급경사에서 입자는 종착할 수 있고 확률은 보존. 접근 위험은 별도 추천 제외 | 물 이동·표류·추락 모델 없음 |
| 구역 전체 일괄 할인 | 30 m 셀별 C(x), P′ ∝ P exp(-C), 마지막에 480 m 구역 집계 | 셀보다 작은 탐지폭은 부분 면적 가정으로 근사 |
| 간격 보정 0 반례 | f_sync 사용하지 않음 | 독립 수색 회차 누적 가정. 팀원 상관·반복 관측 미보정 |
| 업로드 즉시 갱신 | 파싱/검증 → 대기 → 완료·미발견 승인 → 반영 | 모든 최종 상태를 지원하는 기관 업무 시스템은 아님 |
| 확률 합 오류 | Distribution(grid, outside), 연산 후 합 1 검사 | outside는 격자 밖만 의미. 별도 꼬리 모델 없음 |
| B/B′ 이중 표 | 종합 표시 A½, B¼, B′¼; 추천은 세 시나리오 최소 구역 질량 | 가중치는 가정. 스트레스 투표·최악 후회 미구현 |
| 이동시간 초과 | 남은 시간보다 긴 이동 금지. 격자 밖 초기 입자를 경계로 접지 않음 | 단순 지형 이동모형, 실종자 행동 검증 아님 |
| 위험-확률 거래 | 위험 셀 2% 이상인 구역을 일반팀 후보에서 제외 | 2%/30°는 보수적 팀 가정. 안전 판정 인증 아님 |

| 타일 정책 | 표시용 OpenFreeMap 벡터 타일 + 실패 시 로컬 분석 지도 | 표시용 인터넷 필요, PWA 설치/서버 없는 실행 미구현 |
| 과장된 POD | 탐지폭 8/15/22 m 시나리오 범위라고 명시 | 경험적 신뢰구간·교정 결과가 아님 |
| 인계·삭제 모순 | 기본 ZIP에 원본 GPX 제외; 보유 중임을 문서화 | DB/다운로드 사본 자동 삭제 미구현 |

## 계산과 표시의 정확한 의미

- A는 700√시간 m 표준편차의 2D Gaussian 거리 가정이다. 문헌의 q25/q50/q75/q95를 적합한 모델이라고 주장하지 않는다. 초기 위치 오차를 별도 표본으로 더한다.
- B와 B′는 동일 seed로 시작하는 연관 시나리오이다. 지형은 실제 데이터지만 속도·경로 선호·토지피복 계수는 팀 가정이다.
- 물·45° 초과 경사는 이동모형의 종착 상태로 남는다. 수색대 추천 위험 마스크는 별도로 30° 초과를 사용한다. 바다의 확률을 육지로 재분배하지 않는다.
- 지도 밖 확률은 입자/표본으로 추정한다. 표시 0.00%는 바깥에 있을 가능성이 없다는 증명이 아니다. 사후 갱신으로 사전 0 질량이 새로 생기지 않는다.
- 합성 GPX는 정해진 잔디깎기 형태이다. 실제 수색 결과를 재현한 데이터가 아니다.
- C(x)는 경로 길이 × 가정 탐지폭 / 셀 면적을 위치오차 커널에 분배한 탐지강도이다. 경로 밖 먼 셀에는 강도를 추가하지 않는다. 커널은 탐지 관측의 불확실성용이고 실종자 확률의 장벽을 넘는 평활에 쓰지 않는다.
- 서로 다른 수색 회차는 조건부 독립이라고 가정한다. 동일 좌표 경로는 시각만 바꿔도 중복으로 차단한다. 실제 같은 길의 재수색도 차단될 수 있으므로 현장 적용에는 회차 식별/상관 모형이 필요하다.
- 속도 0.08–3 m/s, 점 사이 120초·250 m 조건을 넘는 구간은 계산/실선 표시에서 제외한다. 제외 수가 표시되며 탐지 효과 0은 실제로 수색하지 않았다는 판정이 아니다.
- 구역 POD는 사전 질량으로 가중한 가정상 탐지확률이다. 시나리오별 사후는 따로 정규화하고 종합 지도는 고정 가중 혼합으로 표시한다. 모형 증거에 따른 Bayesian model selection은 하지 않는다.
- 순위는 세 시나리오의 구역 질량 중 최소값에 비례한다. 카드의 전후 순위는 실제 계산값이다. 효율·이동시간 최적화나 스트레스 투표 결과는 아니다.
- 수색 전/후 버튼은 지도 레이어를 비교한다. 카드와 하단 통계는 선택된 버전의 사후 상태이다. 과거 버전에서도 장부·후보 승인 상태는 최신 값을 별도로 보여 준다.

## 9월 20일 추가: 학습 거리 분포 기본 적용, ROW, 팀 밴드, 참여자 계층

- 거리 시나리오 A의 기본값이 학습된 65건 lognormal(도달 가능 반경 절단)로 바뀌었다. `params.distance_model`과 `distance_model_used`(모델 묶음·파라미터·사례 수)가 영수증에 남는다. 종전 700·√시간 가정은 `assumed_sqrt_time`으로 선택 가능하다.
- 구역 순위 규칙을 세 시나리오 최소값에서 기하평균(`core.consensus`)으로 바꿨다. 학습 A가 근거리를 낮게 보는 표본 편향(1 km 미만 사건 제외) 때문에 최소값 규칙이 마지막 확인 위치 근처를 무조건 밀어내는 문제를 확인했기 때문이다. 어느 시나리오라도 0이면 후보에서 빠지는 성질은 유지한다. 카드에 `agreement`(최소/최대)를 추가했다.
- ROW: `row_share`(기본 0.10)를 `with_row`로 outside에 예약한다. 갱신식은 그대로이며 미발견이 반영될수록 outside가 커진다. 발견점 참고 분포에도 같은 값을 적용한다.
- 팀 밴드: `coverage_for(segments, team_size, spacing_m)`는 노력을 n배 하고 폭 (n−1)s의 균일분포 분산(b²/12)을 GPS 커널에 더해 옆으로 퍼뜨린다. 계획기는 `serpentine(zone, band_rows)`로 밴드 폭만큼 행을 건너뛰는 4-연결 경로를 만들고 각 밴드 셀에 n/k 배 노력을 준다. `trajectory.exposure`가 밴드·배율을 받는다. 시간 재생(`temporal.observations`)도 트랙별 팀 정보를 사용한다.
- 계획기 후보는 팀별로 "왕복 가능한 구역" 필터를 거친 뒤 상위 32개를 본다(짧은 계획 시간에 후보가 전부 도달 불가여서 빈 추천이 나오던 문제 수정). `MAX_PACKETS`를 131,072로 올려 학습 A의 넓은 점유에서도 15분 계획이 표집 없이 돌아간다.
- 참여자 계층(`backend/roles.py`): `members`·`mission_status`·`track_purges` 테이블, 코드 해시 저장, `/api/join*` API, `X-Role-Code` 헤더. 인계 완료 시 원본 GPX를 빈 값으로 덮고 삭제 기록을 남기며, 이후 변경 API는 409를 돌려준다. 시간 재생은 원본이 삭제된 임무에서 정적 전파로 자동 복귀한다.
- 배포 프로필 `SEARCHPROOF_DEPLOY_PROFILE`, 구성요소 표 `ml_models.components`, 보고서 개편, 로고·팔레트.
- 검사: 백엔드 114개 통과(이 환경에서 Apple Silicon 부동소수점 비트 일치·미복사 모델 묶음에 의존하는 3개는 Mac에서만 통과), 프런트 단위 14개, Playwright 시나리오(조정자·참여자·봉사자 동의→배정→체크인→중지·가족·보고서) JavaScript 오류 0.

## 9월 18일 추가: 상세 지도와 시간 이동 추정

표시 지도는 OpenFreeMap Liberty 벡터 스타일을 한국어 우선으로 조정했다. 도로·건물·문자를 확률 색상 위에 그리며, 20단계 확대 및 기기 픽셀 배율을 사용한다. 지도 데이터에 없는 건물·농로를 새로 만들어 표시하지 않는다. 연결 실패 시 저해상도 분석 지도로 되돌리고 경고한다. 수색 계산은 여전히 30 m 격자이다.

시간 추정은 저장된 버전의 사후분포에서 출발한다. 과거 수색의 음성증거를 한 번 반영한 뒤, 각 셀의 정확한 질량을 두 개의 가중 경로로 나눠 전파한다. 이동 시간은 경사·토지피복·도로 접근성과 미검증 보행계수로 계산하며, 완료하지 못한 마지막 이동은 원래 셀과 다음 셀 사이에 부분 질량으로 표현한다. 전체 질량과 지도 밖 질량의 합을 유지한다. 서로 다른 미래 시각을 계산해도 난수 경로 앞부분은 같도록 셀·이동 횟수 기반 난수를 쓴다.

이 모형은 실제 관측으로 교정되지 않은 추가 이동 가정이다. A/B는 기본 방향 지속, B′는 추가 경로 추종·내리막 선호를 적용한다. 초기 지도 A의 Gaussian 모델을 미래 모든 시점에 다시 적합하는 기능은 아니다. 속도는 실측이 아닌 모형값이며, 수역·종착 상태의 속도는 0이다. 실제 차량 교통소통정보·날씨·실시간 휴대폰 위치는 연결하지 않았다.

- **실시간 추정:** 서버 시계와 기준 버전 생성 시각 차이를 15초 단위로 계산. 새 관측이 없더라도 가정상 위치분포가 변한다. 화면이 숨겨져 있으면 갱신을 쉬고 복귀 후 갱신한다.
- **시간 미리보기:** 기준 버전에서 +0~120분. 미래 예측이지 그 시간에 확보한 관측이 아니다.
- **보호 경계:** 최대 6시간 이후에는 오래된 기준이라고 경고한다. 실패 시 저장된 지도로 복귀한다. 시간 추정만으로 버전·장부·승인을 쓰지 않는다.
- **보고서:** 시간 추정은 미저장 미리보기이다. GPX 승인·구역 승인은 기준 지도에서 수행하며, PDF/ZIP에는 저장된 기준 버전만 들어간다.
- **주의:** GPX 승인 시각을 기준으로 한 스냅샷에서 출발한다. 원래 수색 시각별로 이동·관측을 완전히 재생하는 동적 필터는 아직 아니다.

API: GET /api/missions/{id}/forecast?version=0 (서버 시계), seconds=1800 (고정 미리보기), /forecast/{layer}.png (같은 시각 레이어). 결과에 기준 버전·추정 시각·계산 시각·속도·교통 미연동 상태·저장 여부를 명시한다.

## 9월 19일 추가: 위성사진 배경

- **일반 지도 / 위성사진** 전환과 **도로·지명** 표시 옵션을 추가했다. MapLibre 인스턴스를 교체하지 않고 배경 레이어만 전환한다. 확률·Search Shadow·구역·트랙·시설은 그대로 유지한다. 배경 선택은 이동모형·확률·버전·영수증을 변경하지 않는다.
- [EOX::Maps](https://maps.eox.at/)의 2025 Sentinel-2 cloudless 합성영상을 사용한다. [제품 사양](https://cloudless.eox.at/documentation/product-list)은 약 10 m, Web Mercator 원본 최대 줌 14이다. 그 이상 확대 시 원본을 확대 표시하며 새로운 세부 정보가 생기지 않는다. 화면에 촬영 연도 대신 **합성영상 연도**와 비실시간·원본 해상도를 명시한다.
- [EOX 이용 조건](https://cloudless.eox.at/documentation/license)의 비상업 교육 이용 범위로 연결한다. 키 없는 공개 URL을 아무 제한 없는 상업 허가로 취급하지 않는다. 화면에 EOxCloudless / EOX / Copernicus / CC BY-NC-SA 4.0 출처와 링크를 유지한다.
- 선택하기 전에는 위성 타일을 요청하지 않는다. 현재 화면 타일만 불러오며 대량 내려받기·사전 캐시·영상 학습·ZIP 포함은 하지 않는다. 영상 공급자에게 화면 범위가 요청되지만 임무·트랙·개인정보를 보내지는 않는다.
- 타일 오류 또는 15초 초기 연결 시간 초과 시 기존 배경으로 되돌리고 재시도 버튼을 표시한다. 일반 지도까지 연결되지 않으면 로컬 분석 배경을 사용한다. 영상 공급자는 무보증 서비스이며 운영 가용성을 보장하지 않는다.

## 영수증·인계의 범위

9월 19일 추가: 새 모의 임무에서 시간대가 있는 마지막 확인/기준 시각과 야간 이동 가정을 선택할 수 있다. 초기 B/B′와 이후 시간 전파에 분 단위 태양고도 기반 이동 시계를 사용한다. v0의 `state_at`(분포 기준시각)을 저장시각과 구분하고 영수증에 고정한다. 절대시각 없는 기존 임무는 변경하지 않는다. 자세한 정의·가정·트레이드오프는 [실종 시각·낮밤 설계](실종시각-낮밤-설계.md)에 있다. AI 학습은 아직 실행하지 않았으며 [학습 시작 안내](AI-학습-시작하기.md)에 확보 자료로 가능한 학습과 불가능한 라벨을 구분했다.

v0는 입력과 시뮬레이션, 이후 버전은 승인된 미발견 반영이다. 코드/지형 입력 해시, 파라미터, seed, 배열 해시, 이전 영수증 해시를 기록한다. 새 반영에는 GPX 원본·정규화 경로·탐지강도 해시도 기록한다. 초기 개발 중 생성한 구버전 영수증은 후속 필드가 없을 수 있다.

ZIP에는 현재 계산 상태, 전체 버전 영수증, 근거 장부, GeoJSON/CSV와 manifest를 담는다. 원본 GPX 및 모든 과거 배열은 담지 않으므로 ZIP만으로 원래 관측에서 완전 재실행할 수 있다고 주장하지 않는다. 동일 코드·지형 및 원본 GPX는 별도 보관이 필요하다. PDF는 보고서 페이지에서 사용자가 인쇄 저장한다.

ZIP 검증은 manifest 대비 파일의 변경 여부를 검사한다. ZIP 전체 바이트의 모든 변화나 manifest까지 다시 쓴 공격을 신뢰된 외부 서명 없이 검출하는 기능이 아니다.

## 검증과 다음 단계

실제 학습·AI 계획 연결(2026-09-19): 사건 65건의 거리 분포와 수색대 61트랙 중 44,285구간의 Random Forest 속도 회귀를 실제 학습했다. 8개 team_id 묶음을 제외한 트랙별 MAE 평균은 0.253 m/s(단순 기준 0.279 m/s)였으며, 독립 사건/현장 성능으로 해석하지 않는다. `AI 계획`에서 1–4팀의 출발점·방식·왕복 포함 시간을 받아 위험 셀을 피하는 제안 경로를 만들고 수색 셀의 추가 탐지효과를 비교한다. 고정된 분포로 단기 계획하는 근사이며 시간별 실종자 행동 AI가 학습된 것은 아니다. 임시 DB에서 2팀 계산·확정·시간 변경 후 자동 재추천·모바일 동작을 확인했고 당시 백엔드 39개 검사가 통과했다. 학습 결과·모델 파일·명령·남은 한계는 [AI 학습 결과와 사용법](AI-학습결과와-사용법.md)에 있다.

명칭 변경·학습 설계(2026-09-19): 화면·브라우저 제목·인계 보고서는 ‘천라지망’, 엔진 표시는 ‘천라지망 AI · 학습 전’으로 변경했다. 기존 DB 경로·엔진 내부 식별자·인계 형식은 호환성을 위해 유지했다. 백엔드 33개와 프런트 단위 검사 7개 통과, 빌드 성공. 읽기 전용 브라우저 검사에서 데스크톱/모바일 표시, 보고서 명칭, JavaScript 오류·가로 넘침 없음을 확인했고 서버 재시작 전후 기존 6개 버전의 영수증 해시가 일치했다. [실시간 수색 범위 학습 설계](천라지망-AI-학습설계.md)는 위치 추정과 인원·시간 제약 계획기를 분리한다. 해당 계획기·새 API·모델 학습은 아직 실행하지 않았다.

시각·낮밤 추가 검사(2026-09-19): 백엔드 32개, 프런트 단위 검사 7개 통과. 별도 임시 DB의 브라우저 검사에서 실제 시각 폼 제출, 해외 브라우저 시간대에서도 KST 일관성, 새벽→낮 전환, 시각에서 계산한 경과시간 표시, 미리보기 조회 전후 영수증 불변, 과거 임무 보존, 모바일 가로 넘침 없음과 JavaScript 오류 없음을 확인했다. 미래 기준시각을 현재 실시간 추정으로 오표시하지 않고 미리보기를 안내한다. 이는 행동 정확도의 검증이나 AI 학습 완료가 아니다.

위성 배경 검사(2026-09-19): 백엔드 25개와 지도/위성 단위 테스트 5개 통과, 프런트엔드 빌드 성공. 실제 EOX JPEG 타일 응답과 데스크톱/모바일 전환, 도로·지명 on/off, 타일 오류 후 일반 지도 복귀 및 재시도를 확인했다. 브라우저 API 요청은 조회뿐이며 전후 임무 버전·영수증 해시가 일치했다. 이는 표시 기능의 동작 검사이지 위성영상의 최신성·현장 정확도 검증이 아니다.

시설 기능 추가 검사(2026-09-18): 백엔드 25개, 지도 스타일 2개 통과. 시설 on/off, 강도 0에서 원래 계산 일치, A/B 불변과 B′ 및 시간 전파 변화, 물 장벽, 확률 합, 기존 임무 보존, 시설 입력의 ZIP 포함을 검사했다. 별도 임시 DB에서 데스크톱/모바일 시설 패널·새 임무 폼·시간 미리보기를 확인했으며 JavaScript 오류·가로 넘침이 없었다. 사용자 임무에는 브라우저 테스트 데이터를 추가하지 않았다.

시설 구현 상세는 [시설 가정 설계](시설-가정-설계.md), 내려받은 실제 자료와 가공/누출 한계는 [공개 학습 자료 안내](../data/research/README.md)를 참조한다. OSM 시설 630개는 관측 시설 목록이고 선호 계수는 미검증 가정이다. 공개 자료 다운로드를 모델 학습 완료로 표현하지 않는다.

2026-09-18 실행 결과: 백엔드 회귀 테스트 19개, 지도 스타일 테스트 2개 통과. 프런트엔드 빌드 성공. 기존 새 임무 → 6종 지도 레이어 → 후보 승인 → 합성 GPX → 미발견 승인 → 장부 → ZIP 검증 → 보고서 → 과거 버전 전환 검사에 더해, 고해상도 화면의 2배 픽셀 캔버스, 30/120분 분포 변화, 실제 15초 뒤 자동 갱신, 네트워크 차단 시 지도 폴백을 확인했다. 1440×1000 / 390×844에서 실행 오류와 가로 넘침은 없었다. 지도/시간 브라우저 검사는 조회만 하며 임무를 변경하지 않는다.

현재 자동 검사는 확률 불변식·승인 절차·동시성·파싱·내부 해시·UI 흐름을 확인한다. 실종자 발견률, POD 교정, 중복/빈틈 30% 감소는 검증하지 않았다. 현장 책임자 인터뷰, 보정/평가 코스 분리, 블라인드 표식 실험, 개인정보/권한 설계가 다음 단계다.
