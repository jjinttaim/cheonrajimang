# 천라지망 — 남은 학습 자료와 현재 차단 조건

검사일: 2026-09-19. 목표는 실제 데이터로 학습한 AI를 사용할 수 있는 상태까지 만드는 것이다. 현재 완료된 거리·수색대 속도 모델만으로 목표 전체를 달성했다고 보지 않는다.

## 이번 확인 결과

데이터 검증 판정은 **제한을 명시하면 연구용 결과 공유 가능 / 실시간 실종자 행동·POD 학습 완료 주장은 근거 부족**이다.

공개 탐지 연구 3개를 추가 수집해 방법·표·그림과 PDF 내장 데이터/링크를 확인했다. 학습할 개별 관측 행은 확보하지 못했다. [출처·영수증·검사](../data/research/detection_sources_2026/README.md). 공개 논문의 요약 결과, 누적 곡선, 공식으로 계산한 POD는 서로 다른 자료다. 마지막 것을 실제 발견 여부처럼 학습하면 기존 공식을 외우게 되며 현장 검증이 되지 않는다.

이 판정은 확인한 출처와 현재 로컬 자료에 한정한다. 인터넷 전체에 사용 가능한 데이터가 없음을 증명한 것은 아니다. 원자료 요청이나 기관 연락은 보내지 않았다.

## 무엇이 있어야 다음 실제 학습을 할 수 있는가

| 학습 목표 | 최소한 필요한 관측 | 현재 부족한 것 |
|---|---|---|
| 시각별 이동·정지와 방향 | 이용 권한 있는 익명 사람/사건 묶음, 시간대 포함 관측 시각, 위치·오차, 이동수단, 관측 범위/누락 | 현재 끝점 자료에는 연속 경로·신뢰 가능한 시각별 정답이 없음 |
| 낮밤·시설 관련 행동 | 위 관측과 같은 시각의 조명/일조·시설 상태, 실제 방문/통과를 구분할 기록, 관측이 없으면 미확인 표시 | 시설에 가까웠다는 것만으로 방문·선호 라벨을 만들 수 없음 |
| 탐지확률·탐지폭 | 실험/코스/회차/수색자 익명 묶음, 표식 실제 위치·상태, 수색 시간/GPS/오차, 발견 여부·시각, 중단 여부, 블라인드 여부 | 검증된 관측 단위의 발견·미발견 기록 없음 |
| 국내 적용 및 수색 효용 | 보정에 쓰지 않은 별도 코스·회차의 위 관측, 일반 지도 기준과 같은 조건의 비교 | 현장 실행과 독립 평가 미실시 |

필수값을 임의로 채우지 않는다. GPS 업로드만으로 미발견으로 만들지 않으며, 중단/미관측/표식 유실은 발견 실패 0이 아니라 별도 상태다. 수색 종료 후 표식이 원래 위치에 남아 있었는지 확인하는 절차도 필요하다. 동일 사람·코스·사건의 반복 관측을 독립 사례 수로 세지 않는다.

## 가능한 확보 경로

1. **안전한 감독 모의 실험**: 장소 허가와 지도교사/현장 책임자의 감독 아래 표식 탐지 결과부터 수집한다. 참여 동의, 공개하지 않는 정답 배치, 정해진 종료 조건, 보정 코스와 별도 평가 코스를 먼저 마련한다. 사람을 실제로 길 잃게 하거나 위험한 야간 지형에 보내지 않는다. 정상 참가자 자료는 보행·표식 탐지 실험이며 실제 실종자 행동의 정답은 아니다.
2. **이용 허가받은 익명 관측**: 보유 기관/연구자가 제공할 수 있는 항목·묶음 ID·측정 정의·사용 범위를 확인한다. 실명, 연락처, 주민번호, 원문 건강정보는 받지 않는다. 정확한 위치는 익명 ID만 붙였다고 익명화가 완료되는 것이 아니므로 승인된 최소 범위로 제한한다. 원문 기사와 연결해 재식별하지 않는다.
3. **저자에게 원자료 문의**: 이번 공개 문헌의 관측 단위 데이터/사전 제공 가능 여부를 묻는 경로다. 사용자 요청 없이 외부 문의를 발송하거나 자료 접근권을 구매하지 않는다. 논문 PDF를 읽을 수 있다는 사실과 원자료 이용 권한은 별개다.

자료를 확보하면 `원본 고정 → 단위·관측/모의 구분 → 사건/사람/회차 분리 → 기준 모델과 비교 → 실패 포함 기록 → 별도 승인 후 연결`을 진행한다. 평가 결과를 본 뒤 같은 평가셋에 맞춰 계속 조정한 값을 외부 검증 성능이라고 보고하지 않는다.

## 목표 상태·다음 행동

- 직전 설명 답변은 상태 전달이지 새 학습 진척은 아니었다. 이번에는 새 1차 출처를 검사하고 원문/무결성 영수증과 학습 부적격 사유를 보존했다. 새 모델 학습은 하지 않았다.
- 현재 핵심 차단 조건은 **실제 시간별 행동·탐지 성패의 이용 가능한 관측과 독립 현장 평가가 미확보**라는 점이다. 같은 자료로 재학습을 반복해도 이 조건을 해결하지 못한다.
- 이번 후속 실행을 기준으로 이 차단 조건을 명시적으로 재확인했다. 전체 목표는 완료 처리하지 않으며, 즉시 blocked 처리하지도 않는다. 향후 자동 실행은 새 사용자 답변·새 자료·실제 실행 중인 수집 작업 유무를 먼저 확인해야 한다. 이미 확인한 논문을 반복 수집하거나 문서만 고쳐 새로운 학습 진척으로 세지 않는다.
- 모의 실험 가능 여부, 허가받은 자료 보유 여부, 또는 저자 문의 준비 방향에 대한 사용자 선택이 다음 실제 학습 경로를 결정한다. 질문은 사용자에게 전달했으며 응답·새 데이터 도착이 확인되지는 않았다.
- 60초/표집 수의 추천 민감도와 완전한 경로 재현 패키지 같은 엔진 검증 과제도 남아 있다. 이 과제를 수행하더라도 행동·POD 정답 부족과 현장 검증 미완료를 해소했다고 주장할 수 없다.
