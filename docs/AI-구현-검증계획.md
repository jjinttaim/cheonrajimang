# 천라지망 학습·추천 구현 작업 / 사전 고정 계획

요청: 실제 학습한 AI를 앱에서 사용할 수 있게 연결한다. 아래는 학습 실행 전에 정한 방법이다. 이 문서는 완료 선언이 아니다.

## 완성 확인표

- [ ] 원본·가공 자료 전체 사용처/제외 사유와 해시 기록
- [ ] 실제 사건 65건의 발견 거리 모델 학습, 사건별 제외 평가, 공간 묶음 보조 평가
- [ ] 실제 수색대 GPS의 속도 회귀 학습, 팀 단위 평가, 단순 기준과 비교
- [ ] 훈련 1회 GPS는 별도 기록 처리/이동 범위 검사에 사용 (실종 정답으로 혼합 금지)
- [ ] 검증 가능한 모델 묶음, 재실행 명령, 평가 결과, 모델 설명 저장
- [ ] 서버 추론, 모델 해시 고정, 손상·미준비·범위 밖 입력 처리
- [ ] 인원·시간·출발 위치·접근 제한을 고려한 수색 구역/경로 추천
- [ ] 새 시각·승인된 미발견 증거에 따른 추천 갱신, 승인과 추천 분리
- [ ] 앱 입력·지도 표시·학습 결과 열람·승인 흐름 완성
- [ ] 임시 DB 통합/브라우저 검사, 기존 임무 보존, 사용 설명
- [ ] 실제 수색에 사용할 성능·현장 안전·개인정보 요건 확인 (현재 증거 없음)

## 고정 학습 방법

1. 발견점: 실제 65건만 사용. 양의 대권거리(m)를 lognormal(loc=0)로 적합. Rayleigh(loc=0)는 비교 기준. Leave-one-case-out으로 NLL, 50/80/95% 반경 포함률과 면적을 함께 기록한다. 위도·경도 정수 1도 격자 묶음을 통째로 뺀 보조 평가를 추가한다. 지도 좌표/시간 모델로 검증했다고 주장하지 않는다. 두 모델 모두 학습하되 lognormal의 채택은 실험적 비교 모드이며 성능 보장 아님.
2. 수색대 속도: CANDIDATE 중 grade가 유한하고 |grade|<=1인 구간. 경사가 누락된 정지점이나 급경사 센서 오차를 임의 채움하지 않고 제외 수·이유를 공개한다. 입력은 abs(grade), 수색 방식 one-hot뿐. 거리·소요시간·사건번호·발견점은 입력 금지. RandomForestRegressor 64 trees, max_depth=6, min_samples_leaf=40, random_state=20260919, n_jobs=2. 트랙별 총 가중치를 같게 한다. 익명 team_id의 8묶음을 하나씩 제외해 평가하며 트랙별 MAE를 먼저 평균한다. 비교는 훈련 자료 수색 방식별 트랙 중앙값의 중앙값. 더 나쁜 모델을 더 좋다고 표시하지 않는다. 이 묶음이 사건/개인 독립성을 완전히 보장하지 않는 한계도 명시한다.
3. 키프로스 1회 훈련: 시간대가 없는 시각은 상대 간격으로만 사용. 사람별 정렬, 120초 초과 간격·비양수 시간·3m/s 초과 구간을 표시한다. 학습용 실종 행동이나 야간 라벨로 쓰지 않는다.
4. 논문 모의 32,500행과 사건별 사후 적합 파라미터는 입력/실제 정답으로 쓰지 않는다. 학습 금지 사유와 원본 해시를 남긴다.

## 구현 경계

학습 환경은 .venv-ml로 분리한다. 런타임은 pickle을 실행하지 않고, 해시 검증한 JSON 결정트리·거리분포 계수를 읽는다. 모델 로딩 오류면 사용 불가를 알린다. 학습 결과와 전체 코드·데이터 해시를 모델 묶음에 고정한다. 기존 임무·영수증을 재작성하지 않는다.

65건의 시간 없는 발견점 모형과 현재 시점 이동 분포를 같은 확률처럼 섞지 않는다. 발견점 모형은 별도의 '학습 발견점 참고' 모드로 제공한다. 시간별 위치는 현재 가정 시나리오임을 표시한다. 수색대 속도 모델은 팀 이동/수색시간에만 사용한다. 시설·야간·POD 계수는 아직 관측 정답이 없으므로 학습 완료로 표시하지 않는다.

계획기는 안전 제한을 먼저 적용하고, 실제 셀 경로의 추가 탐지효과·도착시간·수색시간을 평가한다. 추천 생성은 미발견 증거도 실제 배정도 아니다. 승인에는 기준 지도·모델·요청 해시와 만료시간을 확인하며, 이전 확정 배정을 자동 덮어쓰지 않는다. 운영 지역 확대, 실제 사건 자료, 보정된 POD 확보 시 전체 모델 선택과 평가를 다시 검토한다.
