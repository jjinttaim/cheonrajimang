# 수색 중 이동하는 대상의 경로별 계획 평가

2026-09-19. 목표는 학습된 수색대 속도를 써서 계획한 **방문 시각**과 대상 이동 가설의 **동일 시각 위치**를 연결하는 것이다. 이동 행동·탐지폭을 학습했다고 주장하지 않는다. 기존 고정 지도 계획 및 과거 기록은 보존한다.

## 요구와 경계

- 시간 미리보기/실시간 추정의 계획은 앞으로 5–120분의 이동을 평가한다. 전체 시간은 최초 기준부터 6시간 이내여야 한다. 범위를 넘기면 거절하고 조용히 고정 지도로 대체하지 않는다.
- 마지막 발견점 통계 모드는 시간 정답이 없어 이 계산에 넣지 않는다. 기준 지도만 보는 기존 모드도 고정 분포 계획으로 유지한다.
- 최초 분포에서 같은 경로를 재생하고 계획 시작 이전의 승인된 미발견만 가중치에 반영한다. 미리보기 시점 이후 관찰을 과거 추천에 쓰지 않는다. 계획 경로는 실제 관찰이 아니며 저장된 위치분포를 변경하지 않는다.
- 팀별 출발·도착·수색·복귀 시간과 접근 제한은 유지한다. 학습 수색대 속도와 미보정 야간/토지피복 계수의 역할을 구분한다.

## 계산

`기준 분포 + 과거 승인 관찰 → 일관된 가중 이동 경로 → 후보 수색 경로의 방문 시각 → 추가 발견효과`

기존 이동 엔진의 경로 토큰/난수 규칙을 재사용한다. `coherent-path-survival-v2-adaptive`는 기록 배열 합계 256 MiB와 시나리오당 65,536개 경로 한도 안에서 원래 가중 경로를 모두 사용한다. 초과할 때만 시나리오별 예산을 배분해 층화 표집하고 같은 토큰의 반복은 가중치로 합친다. 작은 시나리오는 가능한 한 전 경로를 유지한다. 두 한도는 메모리·계산량을 위한 구현값이며 통계적으로 검증한 표본 크기가 아니다. 지도 밖 질량은 별도로 유지한다. 표집은 학습이나 실종 사건 수 증가가 아니며, 원래 경로 전체도 실제 가능한 모든 사람의 이동을 뜻하지 않는다. 지도 시작 분포는 계산에 실제 사용한 가중 경로로 표시한다.

계획 중 15초마다 경로의 위치를 기록한다. 셀 간 이동은 두 끝 셀에 분율로 나타내는 기존 근사와 일치시킨다. 수색 경로의 각 30m 변에 대해서 중간 방문 시각을 가장 가까운 기록 시각에 배정한다(최대 7.5초 반올림 오차). 이는 전체 경로·탐지 효과의 오차 상한이 아니다. 양 끝 셀에 각각 길이 절반의 탐지 노력을 준다. 이동/복귀는 수색 탐지로 치지 않는다. 비유한 시각·비정수 셀·4방향 이웃이 아닌 수색 변은 거절한다. 실제 승인 GPX 관찰의 60초 구간 재생은 이번 변경과 별개이며 그대로 유지한다.

경로 k에 기존 배정이 남기는 단위 탐지폭 강도 E_k, 후보의 강도 H_k, 탐지폭 w가 있으면 추가 효과는 `Σ weight_k × exp(-w E_k) × (1-exp(-w H_k))`다. 8/15/22m 가정을 각각 계산한다. 같은 셀이라도 다른 시각에는 다른 경로 집단을 만날 수 있다. 여러 팀이 같은 경로 집단을 만나는 중복은 생존도 곱으로 처리한다. 원래 지도 밖 대상의 발견효과는 0으로 남긴다.

후보 구역은 계획 기간의 시나리오 공통 질량이 높은 최대 32개를 택한다. 현재 순간에 낮더라도 이후 유입되는 구역을 후보에 포함할 수 있다. 후보 경로들에서 시나리오별 가운데 탐지폭 효과의 최솟값/왕복시간을 비교한다. 전역 최적화나 학습된 강화학습 정책은 아니다.

## API·저장·UI

- 계획 요청의 선택 필드 `moving_target=false`는 기존 동작이다. UI는 시간 추정에서 기본 활성화하되 사용자가 끌 수 있게 한다. ENDPOINT_REFERENCE·시간 추정 없는 요청에서는 true를 거절한다.
- 결과에 실제 계산 방식, 원래 모집단·표집 여부·추출 수/유효 경로 수, 실제 시간 해상도·반올림 한도·배열 바이트 수, 시간별 지도 밖 질량, 경로 자료 SHA-256, 수색 셀 도착 시각을 저장한다. 원시 경로는 API에 나열하지 않는다.
- 고정 지도 PNG는 계획 시작 시각의 입력 분포다. 미래 위치 지도라고 표시하지 않는다. 계획 메타데이터/코드 해시는 기존 영수증·ZIP에 포함한다.
- 최대 2개 계획 경로 캐시에 저장되는 경로 배열 합계는 최대 512 MiB다. 임시 배열·지도·평가 자료·동시 요청까지 포함한 전체 프로세스 메모리 상한은 아니다. 기존 임무 DB를 테스트로 변경하지 않고 임시 DB에서 점검한다.
- 열린 AI 패널은 계획 요청을 한 번에 하나만 보낸다. 계산 중 시간만 바뀌면 현재 응답을 받은 뒤 최신 대기 요청 하나만 계산한다. 입력·임무·버전이 바뀐 이전 결과는 숨기되, 브라우저 fetch 취소로 서버 계산까지 중단됐다고 간주하지 않는다. 표시한 계획은 실제 기준 시각에 고정된다. 패널을 닫거나 다른 브라우저에서 실행하는 경우까지 서버 전체의 계산을 직렬화하는 장치는 아니다.

## 통과 검사와 트레이드오프

1. 정지 대상·같은 경로 입력은 기존 고정 모델 점수와 일치해야 한다.
2. 같은 셀에서 일찍/늦게 수색했을 때 도착한 대상만 점수에 들어가는 반례를 검사한다.
3. 동일 시각 중복 팀은 감소하는 추가 효과, 교차 시각 다른 대상은 별도 효과를 가져야 한다. 누적 효과는 전체 확률을 넘지 않아야 한다.
4. 과거/미래 관찰 분리, 확률 합, 표집 재현성, 경계 밖·정지·이동 중 기록을 검사한다.
5. 6시간 한도·발견점 모드 차단·왕복/위험·저장 재열람·인계·기존 요청 재시도를 검사한다.

이전 v1의 60초/8,192 표집에서는 고정한 합성 황혼 임무의 추천이 5초/전 경로 비교와 달랐다. 15초·적응형 예산으로 수정한 두 합성 임무에서는 추천 구역과 동일 기준 재채점 효과가 일치했다([결과](AI-추천안정성-검사결과.md)). 이 결과는 입력 두 개의 수치 검사이지 일반적인 수렴·현장 정확도 증명이 아니다. 큰 임무의 표집, 희소 구역, 15초 사이의 짧은 만남에서는 오차가 남는다. 표집 또는 작은 유효 경로 수에 경고하며 0점이 부재의 증거가 아님을 유지한다. 독립 행동 자료, 탐지폭 보정, 실제 팀 폭/중단/통신 지연 검증이 필요하다.

현재 구현의 유효 경로 경고 기준은 256 미만이며 미보정 구현값으로 노출한다. 모든 시나리오에서 가운데 탐지폭의 추가 효과가 양수인 후보가 없으면 추천하지 않는다. 원시 표집 경로 전체는 저장하지 않아 해시만으로 완전한 독립 재계산 아카이브를 제공하는 것은 아니다. 이 두 한계는 후속 검증·인계 개선 대상으로 남긴다.
