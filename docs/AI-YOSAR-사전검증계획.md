# YOSAR 발견 거리 모델: 적합 전 고정한 실험 계획

2026-09-19. 이 파일은 이번 모델의 파라미터 적합·점수 계산 전에 작성한다. 기존 65건 모델과 수색대 속도 모델의 학습 설정·아티팩트는 변경하지 않는다.

## 자료와 사용 범위

- [YOSAR 공개 서비스](https://services5.arcgis.com/ZY2TU3F6m1lSbSrn/ArcGIS/rest/services/YOSAR_MissingPersonData_v1/FeatureServer)의 보존된 최소 필드 218행을 사용한다. 추가 요청은 `SubjectC='Hiker'`에 해당하는 OBJECTID 목록뿐이다. 의료·개인 특성은 가져오지 않는다.
- 현재 서비스에는 하이커 134행/133개 사건 키가 있다. 그중 1개 사건 키에 Found1/Found2 두 쌍이 있어 의미를 확인하기 전 두 행 모두 제외한다. IPP→Found가 하나인 132개 사건 키를 첫 적합 대상으로 한다. 0거리와 먼 거리는 삭제하지 않는다. 잘못된 좌표·비양수/비유한 위치 오차·교차 사건 연결은 이유를 남기고 거절한다.
- [2014 원 논문](https://doi.org/10.1016/j.apgeog.2013.11.001)의 하이커 분석 수는 130이다. 서비스의 133개 사건 키와 같은 표본이라고 확인하지 못했다. 논문 재현이나 검증된 독립 사건 132건으로 주장하지 않는다.
- 두 점 연결선은 실제 이동 경로가 아니다. 날짜·시간·도로·시설·낮밤·발견 성공률은 학습하지 않는다. 기존 65건과 합치지 않는다. 끝점 근접 검사에서 일치가 없었던 것만으로 두 자료의 사건 독립성을 주장하지 않는다.
- 원자료 및 이번 YOSAR 파생 모델/평가: Paul J. Doherty, Jared Doke, NSF #1031914, [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). 비상업적 연구·모의 훈련 참고 모델이며 저자의 보증을 뜻하지 않는다.

## 좌표 오차와 적합 가정

[2011 원 논문](https://doi.org/10.1111/j.1467-9671.2011.01290.x)은 point-radius 방법, 미터 단위 불확실성 반경과 NAD83 좌표를 설명한다. 서비스의 `Georef_U`, `Georef_U_1`을 이 반경(미터)으로 해석한다. **필드별 단위 사전은 확보하지 못했으므로 논문과 필드명을 연결한 추론**이며 제품에서 명시한다. 이 값은 표준편차나 95% 신뢰구간이 아니다. GRS80 타원체로 두 지점 거리 d를 계산한다.

거리 구간: `L=max(0,d-u_start-u_end)`, `U=d+u_start+u_end`. 기록된 동일 좌표도 [0,U]로 남긴다. 구간 오차 배율 0.5/1/2를 별도 민감도 분석한다. 배율 1이 사전에 정한 기본값이며 결과를 보고 바꾸지 않는다.

로그정규분포의 `-mean(log(F(U)-F(L)))`을 최소화한다. 구간 관측 과정이 거리 분포에 추가 정보를 주지 않는다는 작업 가정(coarsening/interval likelihood)이다. 오차 반경만으로 이 가정이 입증되지는 않는다. 실제 점 위치·경로를 복원하거나 구간 안에 균일한 정답을 만들어 넣지 않는다.

설정: 위치 loc=0, log-scale μ 범위 [log(10m),log(100000m)], sigma 범위 [0.15,3]. L-BFGS-B; 훈련 구간 중점의 중앙값을 초기 중심으로 하고 μ 오프셋 -0.5/0/0.5 × sigma 0.6/1/1.6의 9개 시작점을 사용한다. 수렴 실패·경계 적합은 기록하고 기본 모델로 승격하지 않는다. 난수 seed 20260919. 모든 제외·설정 변경은 새 계획을 먼저 기록해야 한다.

## 평가

1. 사건 키 하나씩 제외한 평가와, IPP 0.1도 공간 블록을 묶은 5-fold GroupKFold를 모두 실행한다. 같은 사건/공간 블록의 행이 훈련과 해당 시험에 겹치지 않는지 검사한다. 공간 블록은 완전한 사건/사람 독립성 증거가 아니다.
2. 각 시험 구간에서 새 모델과 **변경하지 않은 기존 65건 lognormal**의 구간 음의 로그우도를 비교한다. 기존 문서의 점 위치 NLL과 수치 크기를 직접 비교하지 않는다. 새 모델의 지역 내 재학습과 다른 자료에서 가져온 모델의 비교이지 보편적인 우열이 아니다.
3. 예측 50/80/95% 반경 포함률은 위치 오차 때문에 `[U≤radius인 비율, L≤radius인 비율]`로 보고한다. 이는 가능한 포함률의 하한/상한이지 95% 신뢰구간이 아니다.
4. 공간 블록별로 paired loss 차이를 묶어 2,000회 블록 bootstrap하고 2.5/97.5 분위수를 보고한다. 작은 자료·교차검증 재사용 때문에 탐색적 효과 범위이며 외부 확정 성능은 아니다.
5. 오차 배율 0.5/1/2에서 고정된 공간 분할의 점수와 전체 적합 반경 변화를 공개한다. 점수가 가장 좋은 배율을 선택하지 않는다.
6. 숫자가 좋거나 나빠도 전체 결과·제외·원본 해시·분할·코드/계획 해시를 보존한다. 실패하거나 모든 해가 경계이면 모델 발행을 중단한다.

## 앱 채택 조건

모델 파일 무결성, 유한 양수 파라미터, 수렴, 확률 질량 보존, 별도 선택 및 인계 기록 테스트를 통과하면 **명시적으로 선택하는 발견점 참고 모드**로만 연결한다. 기존 기본 모델·시간 시나리오·과거 계획·수색 기록을 덮어쓰지 않는다. 새 모델의 표본 수, 좌표 오차 추론, NC-SA 조건을 선택 화면과 영수증에 남긴다. 이 실험만으로 실시간 실종자 행동·한국 사건·탐지확률·현장 안전은 검증되지 않는다.
