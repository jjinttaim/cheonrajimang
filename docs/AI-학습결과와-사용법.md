# 천라지망 AI: 실제 학습 결과와 현재 사용법

2026-09-19. 이 문서는 학습을 실제 실행한 후 작성했다. **학습 모델과 자동 계획은 작동하지만, 실종자 시계열 행동 학습·현장 성능 검증은 끝나지 않았다.** 현재 사용 범위는 로컬 모의 수색이다.

## 실행한 학습

현재 모델 묶음: `fa9c4ef18f740ea8ba24da5bfea861549c717586c2c0e90c1647223e66589a23`. 최초 묶음 `4c9c75cef64be5b4de0cfc02a91863729aa0f0ab7497b2fbaa4ebf2834f491b2`도 보존했다. `models/current.json`으로 선택하며 각 구성 파일의 SHA-256을 검증한다. 이후 재학습하면 새 묶음을 만들고 기존 묶음은 보존한다. 과거 임무·영수증은 변경하지 않았다.

속도 모델의 입력은 |경사|와 수색 방식뿐이다. 속도를 만드는 거리/시간, 사건번호, 나중 발견점은 입력하지 않았다. GPS 구간 고도로 학습했지만 실제 경로에는 DEM 경사를 사용하므로 자료 분포 차이가 있다. team_id는 독립 사건번호가 아니어서 모든 사건·개인·지형 누출을 차단했다고 주장하지 않는다. 권장 엔진 선택에 사용한 교차검증 결과는 탐색적 비교이며 별도 외부 최종 성능이 아니다.

## 추가 YOSAR 학습의 해석

[사전 계획](AI-YOSAR-사전검증계획.md)에 설정을 고정한 후 적합했다. 현재 서비스의 하이커 134행/133개 사건 키 중 다중 끝점 1개 사건의 2행은 의미가 불분명해 제외했다. 다른 132개를 사용했으며 0거리 18개는 임의의 작은 양수로 바꾸거나 지우지 않았다. 원 논문 분석은 130건으로, 서비스 표본과 같은 자료라고 확인하지 못했다.

끝점 거리의 평균 3.89 km, 중앙값 1.81 km, 사분위 범위 0.92–4.11 km, 최댓값 47.19 km다. 오른쪽 꼬리가 길며 먼 사건도 유지했다. 오차 구간 폭의 중앙값은 818 m이고 최댓값은 약 10.12 km다. 정밀한 GPS 정답으로 취급할 수 없다.

`Georef_U` 필드는 원 논문의 point-radius 미터 반경으로 **추론**해 거리 구간을 만들었다. 이 구간이 정답 거리 분포 외의 추가 선택 정보를 주지 않는다는 작업 가정으로 구간 우도를 적합했다. 필드 사전과 관측 생성 과정을 직접 확인한 것은 아니다. 좌표 오차는 95% 신뢰구간이 아니다.

- 지역 분리 구간 NLL: 새 모델 2.645, 고정 기존 모델 3.762(낮을수록 좋음). 차이 -1.118; 27개 블록·2,000회 bootstrap의 탐색적 95% 분위수 범위 -1.858~-0.580. 이 자료에서의 지역 내 학습과 다른 자료에서 가져온 모델의 비교이며 국내 성능 우열이 아니다.
- 지역 분리 평가의 80% 반경 포함률은 좌표 오차 때문에 **77.3–86.4% 사이**로만 판단할 수 있다. 이는 가능한 포함률의 하한/상한이며 통계적 신뢰구간 또는 보정 완료 증거가 아니다.
- 오차를 0.5/1/2배로 해석하면 전체 적합 80% 반경은 **6.27/5.68/5.16 km**, 95% 반경은 **27.07/22.67/18.23 km**로 바뀐다. 기본값은 사전에 정한 1배이며 결과가 좋아 보이는 배율로 교체하지 않았다. 특히 먼 꼬리의 민감도가 크다.
- 기존 65건과 합치거나 197개 독립 사건이라고 더하지 않는다. 기존 기본 모델과 수색대 속도 트리는 그대로다. 새 모델을 명시적으로 선택해야 한다.

원자료와 이 YOSAR 파생 모델/평가는 Paul J. Doherty, Jared Doke, NSF #1031914의 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 조건으로 제공한다. 비상업적 연구·모의 수색 참고용이며 저자의 제품 보증을 뜻하지 않는다. [데이터와 제한](../data/research/yosar_endpoints_2000_2010/NOTICE.md).

## 앱 사용

1. `start.command`로 열고 **AI 계획** 탭을 선택한다.
2. 팀 수(1–4), 출발 위·경도, 수색 방식, 왕복 포함 시간(5–120분)을 입력한다.
3. **현재 지도 · 시간 이동 가정**은 기존 시나리오 분포와 승인된 미발견을 쓴다. **학습 발견점 참고 → 학습 자료**에서 기존 65건 모델 또는 YOSAR 132개 사건 키의 오차 구간 모델을 고른다. 둘 다 경과시간을 학습한 모형이 아니며 시간 분포와 합치지 않는다. 계산 후에는 **추천에 실제 사용한 모델 이름·분포 지도·구역 질량·지도 밖 잔여**를 표시한다. 계획 지도는 저장 시점에 고정하며, 닫으면 시간 지도 표시로 돌아간다.
4. **AI 수색 계획 계산**을 누르면 경로·구역·이동/수색/복귀 시간·탐지효과 가정 범위를 표시한다. 초록은 계획한 수색, 파랑은 이동, 회색은 복귀다. 실제 GPS 기록으로 간주하지 않는다.
5. **시간 미리보기/실시간 추정**과 **새 지도·시간으로 추천 자동 갱신**을 함께 사용하면 새 분포로 다시 추천한다. 예측 최대 6시간을 넘긴 상태에서는 계획을 차단한다. 자동 갱신은 확정 배정을 자동 변경하지 않는다.
   - 한 번의 계산은 끝까지 받고 그동안 바뀐 시간 중 최신 요청 하나만 이어 계산한다. 입력·임무가 바뀐 이전 결과는 숨긴다. 표시된 계획에는 실제 기준 시각을 적으며, 계산이 느릴 때 현재 시각의 결과인 것처럼 표시하지 않는다. 이 동작은 열린 패널의 요청 관리이며 서버 전체 동시 계산 제한은 아니다.
   - **수색 중 대상 이동도 계산**이 켜져 있으면 수색대의 방문 시각과 대상 이동 가설을 맞춰 평가한다. 계획 종료까지 6시간 이내여야 한다. 끄면 기존 고정 분포 근사다. 기준 지도·학습 발견점 참고 모드에는 시간 이동 계산을 적용하지 않는다.
6. 조정자가 **현장 검토 후 모의 계획 확정**을 누르면 결정 장부에 기록한다. 2분 지난 제안이나 수색 결과 버전이 바뀐 제안은 승인할 수 없다. 승인해도 탐지 흔적·미발견 증거·위치 사후분포가 바뀌지 않는다.
7. **저장한 계획 다시 열기**에서 확정 계획과 최근 20건을 다시 읽는다. 새로고침 후에도 남는다. 다른 버전의 기록을 현재 지도에 겹치지 않으며, 다른 계획으로 대체된 기록을 다시 승인할 수 없다.
8. 인계 ZIP에는 계획 내역, 고정 분포 지도 PNG, 사용 모델의 계수/트리·manifest가 추가된다. 전체 원본 GPS는 여전히 기본 ZIP에서 제외한다.

## 관찰 시각에 따른 갱신

실종·기준 시각을 지정한 임무의 **시간 미리보기/실시간 추정**은 최초 기준 분포부터 다시 재생한다. 승인된 GPX만 대상으로 실제 관찰 시각에 음성 증거를 반영한다. 승인 버튼을 누른 시각이나 업로드 순서는 결과의 시간축을 바꾸지 않는다. 미래 시점의 관찰을 과거 화면에 반영하지 않는다.

엔진 `timed-path-survival-v1`: GPX 구간 끝을 기준 시각부터 고정된 60초 구간의 끝으로 묶는다. 최대 60초 지연 근사다. 같은 입자의 경로·방향·시간 진행을 유지하면서 관찰 시각의 위치에 탐지강도를 적용하고 마지막에 질량을 정규화한다. 도중에 이동 상태를 다시 시작하거나, 마지막 위치에 과거 수색 흔적을 다시 곱하지 않는다. 격자 간 이동 중의 탐지강도는 선형 보간하는 가정이다. 밖으로 나간 질량은 보존하며 재진입은 모델링하지 않는다. 유효 가중 입자 수를 반환하지만 독립 실종 사건의 정확도 검증은 아니다.

제한: 최초 기준 지도 이전의 수색 기록이 있으면 시간 재생을 거절한다. 기준은 수색 시작 전에 만들어야 한다. 6시간 이후는 최신 상태라고 표시하지 않는다. 시각을 지정하지 않은 이전 임무는 기존 정적 전파로 유지하며 화면에 그 차이를 알린다. 저장된 지도 버전은 여전히 **동일 시점으로 간주한 정적 기록 요약**이고, 과거 영수증을 덮어쓰지 않는다. 시간 추정 결과와 정적 요약을 혼동하지 않는다.

## 계획기의 정확한 범위

- 학습된 **수색대** 속도로 30m 4방향 격자의 최소시간 경로를 계산한다. 위험 셀을 통과하거나 대각선으로 가로지르지 않는다. 실제 사유지·울타리·현장 통행 허가를 보증하지 않는다.
- 구역 내 왕복 수색 패턴 중 시간 예산으로 갈 수 있는 부분만 계획하고 복귀 시간을 남긴다. 구역 전체를 수색한 것으로 처리하지 않는다.
- 상위 최대 32개 후보를 탐욕적으로 비교한다. 전역 최적해나 학습된 강화학습 정책은 아니다. 여러 팀의 동일 셀은 남은 추가 탐지효과만 계산한다.
- 각 팀은 한 개 관측 경로로 표현한다. 여러 대원이 나란히 펼쳐 걷는 효과는 학습하지 않았다.
- 시간 추정의 **수색 중 대상 이동도 계산**은 `coherent-path-survival-v2-adaptive`로 방문 시각을 맞춘다. 기록 배열 256 MiB/시나리오당 131,072개(2026-09-20부터; 이전 65,536개) 이내에서는 원래 가중 경로 전체를 쓰고, 초과 시만 층화 표집한다. 이는 메모리·계산량 기준이지 검증된 사건 표본 수가 아니다. 15초 간격 위치에 수색 변의 중간 시각을 대응한다(최대 7.5초 반올림 근사, 전체 예측 오차 상한 아님). 같은 대상 경로에 대한 여러 팀의 효과는 누적 생존도로 중복 제거한다. 미래에 승인된 관찰은 과거 추천에 쓰지 않는다. 과거 v1 계획은 원래 메타데이터 그대로 읽는다.
- 이 계산은 가정된 대상 이동을 고려하는 제한된 후보 경로 탐욕 선택이지, 실제 실종자의 행동을 학습한 정책 또는 전역 최적해가 아니다. 지도는 실제 사용한 **계획 시작 시각의 입력 분포**로 고정된다. 이후 시각의 존재 지도나 실제 GPS가 아니다. 표집 여부·시간별 잔여·유효 경로 수·경로 SHA-256·수색 셀 방문 시각을 계획/인계에 기록한다. 원시 경로 전체는 패키지에 넣지 않아 해시만으로 독립 재계산할 수 있는 완전한 아카이브는 아니다. 두 합성 임무의 수치 비교 및 큰 임무의 한계는 [추천 안정성 검사](AI-추천안정성-검사결과.md)에 기록했다.
- 유효 경로 수가 256 미만이면 표집 불안정 경고를 한다. 이 임계값은 구현 경고값이며 검증된 정확도 기준이 아니다. 모든 시나리오에서 양의 추가 효과를 확인하지 못한 후보는 추천하지 않으며 표집 점수 0을 부재의 증거로 해석하지 않는다. **기준 지도·발견점 모드 또는 해당 옵션을 끈 경우**는 기존 고정 분포 근사다.
- 탐지폭 8/15/22m, 야간 계수, 토지피복 계수, 속도 계산 하한/상한과 0.001 경사 양자화는 구현 가정이다. 표시 탐지효과 범위는 통계적 신뢰구간이 아니다.
- 공개 자료에 시설 방문·주야간 이동·교통 정체·탐지 성공 정답이 없으므로 그 항목은 학습하지 않았다. GPX를 업로드했다는 사실은 미발견 관측이 아니다.

## 재학습·검사

프로젝트 루트에서:

```sh
.venv-ml/bin/python -m pipeline.train_models
.venv/bin/python -m pipeline.prepare_yosar
.venv-ml/bin/python -m pipeline.train_yosar
.venv/bin/python -m pytest backend/tests -q
```

학습 환경을 새로 만드는 경우 Python 3.12 환경에서 `pipeline/ml-requirements.lock`으로 설치한다. 실행에는 sklearn이 필요하지 않다. 모델은 JSON으로 내보내며 sklearn 원본 예측과 **전체 학습 입력에서 최대 차이 0**을 확인했다. 외부 pickle 파일을 불러오지 않는다.

첫 명령은 기존 65건/61트랙 모델을 새 묶음으로 만든다. YOSAR를 포함하려면 다음 두 명령도 실행한다. 마지막 명령만 반복 학습할 때는 이미 준비된 입력의 SHA-256·계획 해시가 일치해야 한다. 각 실행은 새 불변 묶음을 만들며 예전 기록을 지우지 않는다. 학습용 합성 값은 수학 단위 테스트에만 쓰고 실제 모델 아티팩트에 넣지 않는다.

`models/<묶음 ID>/evaluation.json`에 사건·팀 제외 분할, 사건/트랙별 결과, 보지 않은 입력의 속도 예측이 있다. `data_inventory.json`에 원본·가공 파일 해시와 사용/제외 사유가 있다. `exercise_validation.json`은 별도 훈련 검사를 담는다.

## 아직 남은 목표

추가 탐지 문헌 3개(총 74쪽)의 수집·검토 후에도 개별 탐지 관측은 확보하지 못했다. 요약 추정값·누적 곡선·계산 POD를 새 학습 정답으로 변환하지 않았다. 현재 실제 추가 학습에 필요한 항목과 안전한 확보 경로는 [남은 학습 자료 상태](AI-남은학습자료-확보상태.md)에 정리했다. 이번 수집은 새 모델 학습이 아니며 기존 모델을 유지한다.

후속으로 실제 하이커 65건에 독립 지형 타일 31개를 결합한 계수 모델을 **실제로 학습**했다. 공간·40 km 완충 평가 NLL은 거리 기준 7.628, 지형 7.613이었지만 개선 불확실성 범위가 0을 포함해 사전 채택 기준을 통과하지 못했다. 연구 결과는 보존하고 앱 모델은 유지했다. [지형 끝점 학습 결과](AI-지형끝점-학습결과.md). 이 NLL은 극좌표 구역 질량 평가여서 기존 연속 거리/오차 구간 NLL과 크기를 직접 비교하지 않는다.

실제 실종자의 시각별 궤적·검증 가능한 수색 관측, 국내 및 대상 유형별 평가, 독립 POD 보정/시험, 현장 책임자와 안전·개인정보·운영 검토가 필요하다. 자동 검사나 브라우저 동작 성공은 실제 사건에서 발견률이 높아졌다는 증거가 아니다. YOSAR는 후속 검토로 일부 끝점 거리를 별도 학습했지만, 시간 필드와 연결선은 여전히 실제 궤적 학습에서 격리한다. 원래 요청한 현장 활용 수준의 완성은 아직 입증되지 않았다.

추가로 저자 공개 [LiDAR 보행 궤적](../data/research/offtrail_lidar_2025/NOTICE.md)의 원본 ZIP을 확보해 MD5/SHA-256을 확인했다. 후속으로 LAS 165개·39,962점을 전수 검사했다. 좌표계는 EPSG:26912이나 시간 단위 설명과 수치 관계가 맞지 않으며, 참가자/코스 사전·독립 지형 입력도 미확인이다. 학습 라벨을 만들지 않고 별도 격리했다. 논문 분석 표본과 같다고 가정하거나 일반 보행 실험을 실종자 행동·POD 정답으로 바꾸지 않는다.
