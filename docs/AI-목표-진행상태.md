## 다음 우선 작업

1. 계획 경로와 가정된 이동 대상을 시간별로 대응하는 탐욕 선택은 구현했고 두 합성 임무의 해상도/표집 민감도를 검사했다. 현재 15초 기록·적응형 경로 예산에도 큰 임무 표집/짧은 만남·가중 입자 퇴화의 한계가 남는다. 더 넓은 고정 사례 평가가 필요하며, 같은 두 사례 재검사는 독립 성능 평가가 아니다. 경로 해시와 코드를 저장하지만 원시 경로 전체가 패키지에 없으므로 완전한 외부 재계산 아카이브는 아니다.
2. 실제 시각별 실종 궤적 또는 그에 준하는 합법적 공개 자료가 더 필요하다. YOSAR 끝점은 별도 구간 학습했으나, 경과시간 음수·날짜 자정값 문제로 시간 학습은 보류한다. 서비스 표본 수와 논문 분석 수 차이 및 오차 필드 단위 추론이 남았고, 기존 사건과의 독립성도 입증하지 못했으므로 외부 최종 검증으로 부르지 않는다.
3. 독립 지형 특성으로 수색대 속도 자료의 GPS→DEM 분포 차이를 줄이는 방안을 검토한다. 수색대/보행 훈련을 실종자 정답이라고 대체하지 않는다.
4. 학습/평가 분리, 독립 모의 수색 정책 비교와 POD 보정 설계를 실행 가능한 수준으로 확장한다. 필요 자료·현장 협력이 없으면 해당 항목을 완료 처리하지 않는다.

이전 후속 실행에서는 지형 모델 학습 등으로 진척했다. 이후 [남은 자료 확보 상태](AI-남은학습자료-확보상태.md)를 재검사했다. 현재 실시간 행동·POD의 추가 실제 학습에는 이용 가능한 관측 정답과 독립 평가가 부족하다. 새 공개 문헌 검토를 학습 완료로 세지 않으며, 자료 확보 경로에 대한 사용자 입력도 요청했다. 전체 목표는 아직 완료가 아니다.

## 시간 경로 계획 최초 구현 확인 — 아래 수치 개선 전 기록

- `coherent-path-survival-v1`: 가중 경로를 재생해 방문 시각에 점수를 계산한다. 미래에 승인된 관찰을 과거 계획에 쓰지 않음, 정지 대상의 기존 점수 일치, 시차를 둔 동일 구역 수색, 여러 팀의 감소하는 추가 효과, 지도 밖 질량, 낮밤 변화/부분 이동을 검사했다.
- 실제 브라우저에서 시간 미리보기 +30분 → 자동 재추천 → 시간 경로 적용을 확인했다. 모의 입력의 첫 점검 계산 약 0.43초(한 번 측정), 별도 4시간 후 시작·4팀·2시간 계획 점검 약 8.00초(한 번 측정). 지연 보증이나 실제 수색 성능 수치가 아니다.
- 안전·시간·모든 가설 공통 양의 효과를 만족하지 못하면 빈 추천과 이유를 반환한다. 유효 경로 수 256 미만 경고는 미보정 구현 기준이다.
- 기존 6개 버전 해시와 학습 모델 fa9c4ef…는 변경하지 않았다. 이번 변경은 새 행동 학습이 아니라 **학습 수색대 속도를 사용하는 계획기의 시간 처리 개선**이다.

## 추가 자료 전수 검사 후속

- `pipeline/profile_offtrail.py`로 165개 LAS를 모두 검사했다. 39,797개 상대시간 차이가 모두 1이지만 필드 설명은 밀리초이고, GpsTime은 0 또는 128씩 변한다. 반올림을 가정한 일관성 검사는 초 단위 가능성을 지지하나, 저자 확인 없는 자동 단위 변환과 속도 학습은 하지 않았다.
- 조건부 진단을 학습 라벨로 오인하지 않게 `training_rows_emitted=0`, 각 파일의 학습 불가 사유를 저장한다. 기존 모델·임무 기록은 그대로다.
- 대체 STRIDE 연구는 원자료 요청이 필요하고, UK hiking 연구의 결합 학습 자료는 직접 공유 제한이 있음을 1차 출처에서 확인했다. 공개 논문/추론 코드를 학습용 원자료로 혼동하지 않았다. 외부 자료 요청을 보내지는 않았다.
- 상세 증거·재현 명령·확인해야 할 네 조건: [추가 데이터 검사](AI-추가데이터-검사.md). 이 단계는 데이터 품질 진척이며 새 모델 학습이나 현장 성능 개선으로 보고하지 않는다.
- 검사 보고서를 전수 재생성하여 저장본과 구조적 동일성을 확인했다. 보고서 SHA-256은 `84f281803518191e84478a57caacfa7edbcb3a2be47efec587604493eb1ec4d5`다. 백엔드 전체 67개 테스트 통과(기존 라이브러리 사용 중단 예고 경고 2개), 실행 앱 available=true, 모델 fa9c4ef… 무결성 확인, 기존 버전 6개 해시 불변을 다시 확인했다.

## 실제 사건 지형 학습 후속

- 새 사전 계획을 고정한 후 실제 사건의 지형 계수 두 개를 학습했다. 374,400개는 후보 구역 수이고 독립 정답은 65건이다. 준비 자료 ID `2f594fee…`, 실행 ID `166970ce…`에 출처·계획·코드·배열 해시와 모든 fold를 보존했다.
- 25개 공간 묶음/40 km 완충 주 평가와 65회 사건 제외 보조 평가를 완료했다. 평균 개선은 작고 불확실성 범위가 0을 포함해 **NOT_ADOPTED**로 판정했다. 평가 실패를 설정 변경으로 감추지 않았다.
- [학습 결과·수치 해석·재현](AI-지형끝점-학습결과.md). 기존 학습 모델·임무 기록은 유지한다. 새 모델은 실시간 실종자 행동·밤·시설·POD의 학습이나 현장 발견 성능 개선을 뜻하지 않는다.
- 저장된 130개 held-out 예측(공간 평가 65개 + 사건 제외 65개)을 재계산해 일치함을 확인했다. 모든 40 km 제외 규칙·bootstrap·채택 판정도 재검사했다. 전체 백엔드 74개 테스트 통과(기존 경고 2개), 운영 모델 fa9c4ef… 및 기존 6개 버전 해시 동일, 앱 available=true 확인.

## 시간·표집 수치 개선과 느린 계산 처리

- 동결된 [수치 검사 계획](AI-추천안정성-검증계획.md)에 따라 두 합성 임무를 비교했다. DUSK에서 기존 방식의 추천 불일치를 확인해 15초 기록·256 MiB 배열 예산 아래 전 경로 우선 사용으로 수정했다. 문제 발견 전·후 보고서는 모두 보존한다. 상세 수치·사후 수정 범위·한계는 [검사 결과](AI-추천안정성-검사결과.md)에 기록했다.
- 시간 간격·표집 수를 분리해 평가하고 잘못된 시각/셀 연결 반례를 추가했다. 현재 두 사례에서 5초 비교와 추천 구역·재채점 효과가 같지만, 현장 정확도나 모든 조건의 수렴을 주장하지 않는다. 별도 4팀/2시간 모의 계획의 한 번 측정은 약 22.28초이며 일부 경로 표집이 남았다.
- 자동 갱신이 긴 계산을 반복 취소하던 문제를 수정했다. 열린 패널은 계산 하나를 완료한 뒤 최신 대기 요청 하나만 처리한다. 모형 연결 상태가 뒤늦게 로드될 때 이미 연 과거 계획을 지우던 문제도 브라우저 실패 검사에서 발견·수정했다.
- 최신 점검: 백엔드 84개 통과(기존 사용 중단 예고 경고 2개), 프런트 단위 14개 통과, 빌드 성공(기존 큰 번들 경고), AI 브라우저 전체 흐름 성공. 지연 응답 중 +35→40→45분 변경 시 계획 요청은 +35/+45분 두 번뿐이고 최대 동시 요청은 1이었다. 모델 상태 응답을 늦춘 과거 계획 재열람도 통과했다.
- 모바일 결과에서 15초 해상도·전 경로/표집 구분·계획 기준 시각을 시각 확인했다: `artifacts/ai-moving-target-numerics-mobile.png`. UI 확인은 실제 발견 성능 평가가 아니다.
- 기존 모델·6개 버전의 해시는 동일하다. 이번 개선은 **새 데이터 학습이 아닌, 기존 학습 모델을 쓰는 계획기의 수치·사용 안정화**다. 실제 실종자 시계열·탐지 정답 확보와 독립 평가 없이는 전체 목표를 완료할 수 없다.
