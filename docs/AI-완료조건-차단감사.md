# 천라지망 AI — 완료 조건과 외부 입력 필요 감사

검사일: 2026-09-20. 목표: **실제 작동하는 AI를 데이터로 학습시켜 사용할 수 있는 상태로 만든다.** 설계·데이터 검증 프레임으로 현재 코드, 학습 산출물, API와 데이터 보유 상태를 대조했다. 목표를 보행 실험 화면 하나의 완성으로 축소하지 않는다.

## 판정

**전체 완료가 아니다. 현재 확보 자료만으로 추가 학습을 반복하는 단계에서 벗어나, 새 관측자료·독립 평가 또는 사용 범위에 관한 사용자 판단이 필요하다.**

직전 목표 실행은 **진척**이었다. 실제 5분 보행 214구간 평가, 동일 생성 코드의 재현 검사, 집계 평가 API와 앱 표시를 추가했다. 이번 검사는 그 성능을 새로 향상시킨 학습이 아니라 현재 차단 조건의 재확인이다. 문서 작성 자체를 새 학습 진척으로 세지 않는다.

## 새 실행·입력 여부

프로젝트의 현재 `data/research`, `data/ml`, 모델 묶음과 출처 목록을 확인했다. 기존 공개 자료·GeoLife 평가 외에 새 학습 관측이 들어온 증거는 없다. 프로세스 목록에는 로컬 웹 서버가 실행 중이지만 자료 수집·정제·학습·평가 프로세스는 없었다. 따라서 진행 중인 학습을 기다리는 상태가 아니다. 웹 서버는 중단하지 않는다.

이는 **현재 접근 가능한 프로젝트 자료**에 대한 판정이다. 인터넷 전체에 자료가 없다고 주장하지 않는다. 이전 검색·원문 검토의 확보/미확보 경계는 `data/research/README.md`, `docs/AI-남은학습자료-확보상태.md`에 기록돼 있다.

## 검토한 대안

- 동일 평가 자료로 모델을 계속 조정하면 새로운 독립 검증이 되지 않는다. 실패한 채택 기준을 낮추거나 결과를 지우지 않는다.
- 일반 보행 궤적을 더 학습하는 것은 가능하지만, 이를 실제 실종자 행동·탐지 관측으로 재분류하면 원래 목표의 증거를 대체하게 된다.
- 합성 수색 환경이나 코드 입력 양식을 추가하는 것만으로 실제 행동·POD의 누락된 관측이 생기지 않는다. 이 단계의 반복을 현장 활용 완성으로 세지 않는다.
- 실종 사건 원자료 요청, 기관 협업, 감독된 표식 실험은 외부 조율·이용 범위·동의가 필요하다. 사용자 대신 연락하거나 현장 실험을 실행하지 않았다.
- 공모전·모의 수색용 완성과 실제 현장 투입은 다른 완료 조건이다. 사용자에게 적용 범위를 확인 요청했으며 이 감사 시점에는 답변이 도착하지 않았다. 작은 범위를 임의로 골라 전체 완료를 선언하지 않는다.

## 연속 차단 조건 확인

1. GeoLife 학습·실험 화면 구현 실행: 실제 보행 모델은 얻었지만 실종자 시간별 행동·탐지 정답과 현장 검증이 없음을 확인.
2. 시간 누적 예측 검사 실행: 실제 보행 후속 검사를 수행했으나 같은 데이터/대상 범위의 한계가 남았고 새 현장 검증으로 볼 수 없음을 확인.
3. 이번 완료 조건 감사: 자료·모델·실행 중 작업을 다시 확인했으며 동일한 관측/검증 공백과 사용 범위 미확인이 남음.

앞의 두 실행에는 실제 진척이 있었으나 동일 차단 조건은 해소되지 않았다. 현재 그 조건을 넘기 위해서는 외부 입력이 필요하다. 전체 목표는 **완료가 아닌 blocked(외부 입력 필요)**로 전환할 조건에 해당한다. 재개 시에는 새 자료/사용 범위에 맞춰 차단 여부를 새로 감사한다.

## 재개에 필요한 입력

다음 중 한 경로가 구체화돼야 한다.

1. **공모전·감독 모의 수색용**이 완성 목표라는 사용자 확인. 그 경우에도 학습된 부분·가정·실패 결과를 유지하고 남은 연결/발표 요구를 따로 확인한다. 확인만으로 자동 완료 처리하지 않는다.
2. **실제 현장 투입 목표**라면 이용 가능한 익명 시각별 경로/수색 탐지 관측과 독립 평가를 진행할 협력 경로. 개인 식별정보를 임의 수집하거나 관측되지 않은 정답을 채우지 않는다.

현재 결과물은 그대로 사용할 수 있다: [수색 앱](http://127.0.0.1:8000/), [보행 학습 실험실](http://127.0.0.1:8000/?view=walking-lab), [학습 결과](AI-학습결과와-사용법.md), [시간 예측 검사](AI-GeoLife-시간예측-검증결과.md).
