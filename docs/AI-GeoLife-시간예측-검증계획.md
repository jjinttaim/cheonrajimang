# GeoLife 시간 누적 예측 검증 — 모델 변경 없는 후속 계획

이 문서는 아래 위치 예측 점수를 계산하기 전에 고정한다. 앞서 확인한 정보는 v1의 30초 범주/속도 평가, 시각 중복 감사, 연속 5분 자료의 **개수**뿐이다. v1 최종 평가 사람은 이미 다른 지표로 살펴보았으므로 이 검사를 새로운 외부 검증으로 부르지 않는다.

## 목적과 동결 대상

천라지망에서 필요한 것은 다음 속도의 예측뿐 아니라 시간이 지난 뒤의 위치 분포다. 같은 모델을 반복 실행한 결과가 실제 보행 기록과 얼마나 맞는지 확인한다.

- 모델 ID: `a0d0ebfd08ac11f565e119ac44d9b92dd76fb286e6aeae780b3c130c5b6390b1`.
- 기존 학습·검증·최종 평가 분할 및 모델 파일을 변경하지 않는다. 이 결과로 재학습·하이퍼파라미터 조정·기존 채택 기준 완화하지 않는다.
- **앱 실험실과 같은 정보 조건:** 출발 위치만 안다. 실제 직전 속도·방향·이후 위치를 예측 함수에 전달하지 않는다. 초기 속도는 학습 분포, 초기 방향은 균등 분포이다. 지형·시설·낮밤을 입력으로 사용하지 않는다.
- 30, 120, 300초 도착 위치를 모두 평가하며 300초가 주 분석이다. 낮은 점수의 시점만 골라 결론을 쓰지 않는다.

## 실제 도착점 만들기

1. 저장된 `walking_samples.npz`에서 v1의 최종 평가 사람 5명만 사용한다.
2. 같은 사람·트랙에서 시각이 정확히 30초씩 증가하고, 앞 행의 다음 이동 벡터와 뒤 행의 직전 이동 벡터가 정확히 같을 때만 이어 붙인다. 공백·트랙 경계·중복 제거로 끊긴 구간은 건너지 않는다.
3. 연속 예측 행 10개(5분)씩 겹치지 않게 묶는다. 시작 위치를 원점으로 놓고 1/4/10개 벡터를 누적해 실제 30/120/300초 상대 도착점을 얻는다. 절대 좌표는 사용·공개하지 않는다.
4. 현재 확인한 개수는 5명, 214개 5분 창이다. 사람별 52/30/7/89/36개이며 적은 사람도 임의 제외하지 않는다. 전체 정제 표본과 달리 5분 연속 기록이 남은 선택된 부분집합이다.

## 기준 모델과 점수

비교 대상은 동일하게 출발 위치만 알고 있다.

- **학습 Markov 모델:** 앱 실험실과 같은 생성 코드.
- **일정 속도·방향 기준:** 학습 집합의 초기 속도 분포에서 뽑은 속도와 균등한 초기 방향을 계속 유지한다. 실제 직전 속도는 사용하지 않는다.
- **정지 기준:** 출발점에 계속 있다고 예측한다.

각 확률 모델·시점에 대해 32,768개 경로를 생성한다. 첫/둘째 독립 표본의 seed는 20260920/20260921, 수치 민감도 반복은 20260922/20260923이다. 모든 평가 창은 동일한 위치-전용 정보 조건이므로 같은 생성 표본을 공유한다. 실제 경로에서 미래 속도를 꺼내 시뮬레이션을 교정하지 않는다.

주 지표는 **에너지 점수** `mean(|X-y|) - 0.5*mean(|X-X'|)`이며 낮을수록 좋다. 두 번째 항은 서로 독립적으로 생성한 경로 쌍을 사용한다. 2차원 상대 위치·미터 단위, α=1이다. 식의 근거: [Pic 외, ASCMO 2025, 식 12](https://ascmo.copernicus.org/articles/11/23/2025/index.html). 이것은 위치 확률 예측의 평가이지 구조 성공률이나 POD가 아니다.

보조 지표:

- 모델이 생성한 반경 50/80/95%에 실제 도착점이 들어온 비율. 반경 분위수는 검증된 신뢰구간이 아니다.
- 실제 이동거리의 평균·중앙값·사분위 범위, 모델 반경 분위수.
- 사람별 점수·포함률, 사람 간 같은 가중치의 평균과 중앙값.
- 두 독립 Monte Carlo 반복에서 평균 점수/모델 순서가 달라지는지.
- 각 기준 대비 사람별 점수 차이의 paired bootstrap 2,000회, seed 20260924. 동일 사람의 수많은 창을 독립 사람처럼 부풀리지 않는다. 이 구간은 5명에서의 탐색적 구간이며 다중 지표를 모두 포함하는 동시 신뢰구간이 아니다.

## 판정과 사용 범위

기존 **NOT_ADOPTED** 판정은 유지한다. 이 검사로 평가 인원이 늘지 않고 실종자 자료가 되지도 않는다. 결과가 나쁘면 앱에 해당 시점의 실제 포함률과 한계를 표시하고, 실제 수색 추천 연결은 보류한다. 결과가 좋더라도 일반 보행·동일 데이터셋의 제한된 증거이며 실종자 수색 성공을 주장하지 않는다.

원자료·모델의 MSR-LA 제한은 그대로 준수한다. 원본·개인별 행·위치 자료를 웹에 노출하지 않고 집계 성능만 제공한다. 모델·데이터·이 계획·실행 코드 해시를 평가 영수증에 기록한다.
