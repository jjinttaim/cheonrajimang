# 시간 경로 계획기의 수치 근사 검사

2026-09-19. **새 행동 AI 학습이나 현장 발견률 평가가 아니다.** 기존 학습 수색대 속도·한림 지형 위에서, 같은 합성 임무의 계산 해상도만 바꾼 검사다.

## 고정 비교와 발견한 문제

계산 전에 [비교 계획](AI-추천안정성-검증계획.md)의 두 임무·지표를 고정했다. 모든 추천을 동일한 **5초/원래 가중 경로 전체** 위에서 다시 채점했다. 이 비교 기준도 이동·탐지 가정을 쓰며 연속시간 정답이나 전역 최적해가 아니다.

| 임무 | 이전 60초/8,192 표집 추천 | 수정 15초/적응형 추천 | 5초/전 경로 비교 추천 |
|---|---|---|---|
| DAY | 496, 496 | 496, 496 | 496, 496 |
| DUSK | 496, 497 | 496, 496 | 496, 496 |

구역 번호는 두 팀의 순서다. 같은 구역도 실제 수색 셀·시간·추가 효과가 다를 수 있으므로 구역 일치만으로 통과 처리하지 않았다.

- DUSK 이전 추천의 공통 기준 재채점 최악 시나리오 효과는 0.0011932541, 비교 추천은 0.0012809116이었다. 부호 있는 차이는 −0.0000876574다. 이는 확률 단위의 **가정 탐지효과**이며 실제 발견율이나 전역 최적 대비 후회가 아니다.
- 15초/8,192만 쓰면 DUSK 추천은 496, 464로 여전히 달랐다. 시간 간격만 줄이는 것으로는 충분하지 않았다. 2,048/4,096 표집 결과와 불일치도 원본 보고서에 남겼다.
- 같은 빠른 대상이 60초 사이에 잠깐 방문하는 합성 반례에서, 60초 기록은 만남을 놓쳐 탐지 강도 0을 반환했다. 15초 기록은 해당 방문을 반영했다. 다른 짧은 만남까지 모두 포착한다는 보장은 아니다.

## 반영한 변경

1. 계획 중 위치 기록을 60초에서 15초로 줄였다. 최근접 기록 시각 반올림의 최대 차이는 30초에서 7.5초가 됐다. 전체 예측 오차의 상한은 아니다. 승인 GPX 관찰의 기존 60초 재생은 바꾸지 않았다.
2. 가능한 경우 원래 가중 경로 전체를 사용한다. 세 시나리오 기록 배열 합계 256 MiB·시나리오당 65,536개를 넘을 때만 예산을 나눠 표집한다. 한도는 구현상 선택이며 교정된 표본 수가 아니다. 원래 경로도 합성 이동 가정이지 모든 실제 경로가 아니다.
3. 실제 표집 여부·원래 경로 수·추출 수·시각 간격·배열 크기를 결과에 저장하고 화면 경고에 사용한다. 잘못된 방문 시각/셀 연결은 거절한다.
4. 자동 추천은 열린 패널에서 단일 요청만 실행하고, 계산 도중 갱신된 입력은 최신 대기 요청 하나만 남긴다. 시간만 바뀌었으면 완료한 이전 시각 결과도 그 시각을 붙여 보여준다. 임무/주요 입력이 바뀐 결과는 숨긴다. 다른 탭·브라우저까지 제한하는 서버 작업 큐는 아니다.

15초/적응형 설정은 위 문제를 확인한 뒤 선택한 **사후 수정**이다. 동일한 두 임무 재검사는 독립 홀드아웃 평가가 아니라 회귀 확인이다. 수정 후 두 임무 모두 비교 추천과 구역·공통 기준 재채점 효과가 같았으며 시작 구역 분포의 총변동거리도 0이었다.

## 비용과 남은 한계

- 원래 경로 수는 DAY 16,124/2,928/3,484, DUSK 44,838/9,594/12,442였다. 새 설정은 이 두 임무에서 전 경로를 사용했다. 한 번씩 측정한 계산 시간은 각각 약 0.86초/1.96초다. 반복 성능 측정이나 지연 보증이 아니다.
- 별도 임시 DB에서 +4시간 시작·4팀·2시간 계획은 약 22.28초 걸렸다. 481프레임, 배열 262,101,624바이트, 사용 경로 11,984/9,594/12,442개였다. 첫 시나리오는 원래 44,838개에서 12,806회 추출해 중복을 합쳤다. API·왕복 예산·기록 비변경을 확인했지만 이 큰 사례의 추천 안정성은 보장하지 않는다.
- 캐시 2개의 경로 배열만 최대 512 MiB다. 다른 배열·지형·동시 요청까지 포함하는 전체 RAM 상한이 아니다. 표집, 15초 미만 만남, 30m 셀 근사, 후보 32개 탐욕 선택, 낮은 유효 경로 수의 불확실성이 남는다.
- 실제 실종자 시간별 이동·시설/야간 선호·POD는 여전히 미학습/미보정이다. 학습 모델 `fa9c4ef…`는 바꾸지 않았다.
