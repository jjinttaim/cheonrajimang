# GeoLife 일반 보행 모델 — 사전 고정 계획 v1

작성 목적: 실제 라벨이 있는 공개 GPS로 학습 가능한 부분을 학습한다. 이 계획은 정제·적합·성능 확인 전에 작성하며, 결과가 나빠도 수정하지 않는다.

## 허용 범위와 출처

- Microsoft GeoLife 1.3 원본 ZIP SHA-256: `1107c5ac064d0a23c8d021a8736a77e53abc75b227062e6260342c6a8d86bdb6`.
- 182명, 18,670개 PLT를 실제 압축 목록에서 확인했다. labels.txt는 69개이며 walk 라벨 보유자는 63명이다. 안내서의 73명 라벨/일부 17,621궤적 표기와 일치하지 않으므로 실제 파일 수를 사용한다.
- 동봉 User Guide-1.3.pdf의 MSR-LA: 비상업적 연구·교육·공개 시연 등 허용, 원자료 및 파생물 재배포 금지 문구가 있다. 원자료·정제 자료·모델은 로컬 연구용으로 격리하고 인계 ZIP·공개 정적 폴더·자동 업로드에 포함하지 않는다. 모델 외부 배포 및 상용화는 별도 이용 조건 확인 전 금지한다.
- 일반 일상 보행이며 실종·인지 저하·구조대·한국 현장 데이터가 아니다. 시설 선호, 밤 행동, 교통, POD를 학습했다고 표현하지 않는다.

## 정제 규칙

1. UTC 시간과 실제 `walk` 라벨만 사용한다. 속도로 보행 라벨을 만들어내지 않는다.
2. 라벨 중복 구간(다른 종류 포함)은 제외한다. 유효 좌표·시간이어야 한다.
3. 비증가 시간, 15초 초과 GPS 공백, 순간 속도 4 m/s 초과, 라벨 변경에서 구간을 자른다. 그 경계를 가로질러 보간하지 않는다.
4. 각 연속 구간에서 UTC 30초 격자로 선형 보간한다. 연속 두 이동 벡터(총 60초 이상)로 이전 평균 순이동 속도→다음 30초 속도·상대 회전각 한 표본을 만든다. 지형 경로 길이가 아닌 GPS 순변위이다.
5. 속도 구간 경계는 0, .25, .75, 1.25, 1.75, 2.5, 4 m/s. 회전은 45도 간격 8개; 이전/다음 속도가 .25 미만이면 방향 불확정 상태 한 개를 사용한다.
6. 동일 사람·표본 시각 중복은 한 번만 보관한다. 동일 PLT 바이트 중복은 사람 간에도 한 번만 보관한다. 다른 사람의 동일 60초 GPS 표본(소수점 6자리)도 중복 제거한다. 겹친 동행·같은 지역 효과를 완전히 제거한다고 주장하지 않는다.
7. 좌표를 학습 테이블에 저장하지 않는다. 익명 사람 ID·트랙 ID·UTC 시각·국소 이동 벡터·속도·범주만 로컬 보관한다. 원 ZIP에는 민감한 실제 궤적이 있으므로 배포하지 않는다.

## 분리와 학습

- 100개 이상 유효 표본을 가진 사람만 분석한다. SHA-256(`geolife-v1:`+사람 ID) 순서로 사람을 정렬해 앞 60% 학습, 다음 20% 검증, 나머지 최종 평가로 고정한다. 같은 사람은 절대 둘 이상의 집합에 들어가지 않는다.
- 최소 30명 및 최종 평가 6명이 필요하다. 부족하면 결과는 탐색용으로만 남긴다.
- 한 사람의 전체 표본 가중치 합을 1,000으로 맞춘다. 많이 기록한 사람이 모델을 독점하지 않게 한다.
- **학습 모델:** 이전 속도 범주를 조건으로 다음 속도 범주 × 회전 범주 결합 확률을 최대우도 빈도에서 적합하는 1차 Markov 모델. 각 결과에 Dirichlet 0.5를 더한다. 신경망이 아니라 데이터로 적합하는 확률 모델이다.
- **기준 모델:** 이전 속도를 무시한 동일 결과의 전체 빈도 모델, 같은 0.5 평활.
- 각 속도 범주의 대표 속도·초기 속도 분포도 학습 집합에서만 추정한다. 검증·평가 자료를 재학습에 합치지 않는다. 하이퍼파라미터 탐색 없음.

## 사전 채택 기준

- 1차: 최종 평가의 사람별 평균 음의 로그우도(NLL)를 다시 사람 간 평균한다. 기준 대비 상대 개선 ≥1%, 사람 단위 paired bootstrap 2,000회(seed 20260920)의 NLL 개선 95% 구간 하한 >0, 위 최소 인원 기준을 모두 만족하면 **일반 보행 다음 30초 예측에만 채택**한다.
- 보조: 속도 평균절대오차(m/s), 결합 범주 Brier score, 사람별 성능, train/validation/test 표본수. 실패도 보존한다.
- 연속 반복 생성은 시연이며 장기 위치 예측 성능이 검증됐다는 뜻이 아니다. 최대 5분만 제공하고, 지형·위험지역·수색 관찰을 무시하는 독립 실험 화면에서 제공한다. 기존 실종자 지도·추천·인계 결과에는 자동 적용하지 않는다.
- 원자료/프로토콜/정제·학습 코드/정제 데이터/모델 해시 및 사람별 분할을 영수증에 남긴다. 웹 API는 모델 전체·실제 GPS·사람별 표본을 반환하지 않고 집계 결과와 새로 생성한 시뮬레이션만 제공한다.
